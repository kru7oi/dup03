Задание 2. Выбор ОС для АРМ

№ Ситуация Оптимальная ОС Обоснование
1 АРМ инспектора ГПН Windows 10/11 Pro или Astra Linux SE АИС «Электронный инспектор» и MS Office работают на обеих. Windows — привычнее, Astra — соответствует импортозамещению.
2 АРМ диспетчера ПСГ (ограниченный доступ) Astra Linux Special Edition Сертифицирована ФСТЭК для работы с гостайной до «особой важности». Мандатный контроль доступа, сертифицированное шифрование.
3 АРМ аналитика МЧС (Python, СУБД) ALT Linux Workstation или Ubuntu LTS Linux лучше подходит для работы с Python, PostgreSQL, аналитическими инструментами. Бесплатно, стабильно, много готовых пакетов.

Методические указания

На что обращать внимание при проверке

  • Задание 1: студенты должны реально открыть сведения о системе, а не заполнять «на глаз». Проверьте, что значения совпадают с реальными характеристиками их ПК.
  • Ситуация 2: ключевое слово — «ограниченный доступ». Это значит, что нужна ОС с сертификатом ФСТЭК. Windows без спец. настроек не подходит.
  • Ситуация 3: для аналитика Linux предпочтительнее из-за экосистемы инструментов (Python, R, PostgreSQL). Но допустим и ответ «Windows + WSL».
Типичные ошибки
  • Путают системное и прикладное ПО (например, относят MS Word к базовому)
  • Не знают о существовании российских ОС (Astra Linux, ALT Linux)
  • Выбирают ОС без учёта требований ИБ (например, Windows Home для работы с гостайной)
  • Не могут найти сведения о системе на своём ПК

Вопросы для обсуждения на занятии

  1. Почему в госструктурах всё чаще переходят на российские ОС?
  2. Что такое сертификат ФСТЭК и зачем он нужен ОС?
  3. Чем отличается Windows Pro от Windows Home?
  4. Можно ли на одном ПК установить две ОС (dual boot)? В каких случаях это нужно?
  5. Почему драйверы — это системное ПО, а не прикладное?

Дополнительная информация для преподавателя

Российские ОС и их сертификация:

ОС Разработчик Сертификация Применение в МЧС
Astra Linux SE РусБИОС (ГК Астра) ФСТЭК, до «особой важности» АРМ с гостайной, серверы
Astra Linux CE ГК Астра Базовая Обычные АРМ, замена Windows
ALT Linux Базальт СПО ФСТЭК (некоторые редакции) Образовательные учреждения, АРМ
ROSA Linux НТЦ ИТ РОСА ФСТЭК Госструктуры, АРМ
Red OS Ред Софт ФСТЭК Серверы, АРМ

Команды для получения сведений о системе в Windows:

  • winver — версия Windows
  • msinfo32 — полные сведения о системе
  • dxdiag — сведения о DirectX и оборудовании
  • systeminfo (в CMD) — подробная информация
  • Параметры → Система → О системе — GUI-способ
