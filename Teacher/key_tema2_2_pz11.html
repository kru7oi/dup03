Материалы для проверки и проведения занятия

Для служебного пользования

Опрос в начале занятия

  1. Для чего нужны таблицы в документах?
  2. Какие элементы имеет таблица?
  3. Чем строка отличается от столбца?
  4. Как создать таблицу в текстовом процессоре?
  5. Зачем нужно объединять ячейки?
  6. Почему нельзя оформлять таблицу с помощью пробелов и тире?
Ожидаемые ответы
  • Таблицы нужны для структурирования данных, сравнения показателей и быстрого поиска информации.
  • Строки, столбцы, ячейки, заголовок, тело таблицы, примечания.
  • Строка — горизонтальный ряд, столбец — вертикальный ряд.
  • Через вкладку «Вставка» → «Таблица», диалог вставки, преобразование текста в таблицу.
  • Для создания общих заголовков и нестандартных структур.
  • Такая «таблица» не является настоящей таблицей, её нельзя редактировать, сортировать и форматировать.

Организация занятия

  • Студенты работают индивидуально за ПК.
  • Проверьте, что текстовый процессор позволяет вставлять таблицы и настраивать границы.
  • Рекомендуется альбомная ориентация, так как таблица содержит 7 столбцов.
  • Данные для таблицы студент берет со страницы занятия или из раздаточного файла.
  • Основное время — 18–20 минут на создание и оформление таблицы.
  • Проверка имени файла и колонтитула обязательна, так как это позволяет идентифицировать работу.
Контроль самостоятельности Таблица может быть выполнена по образцу, но данные должны быть внесены самостоятельно. Если студент просто скопировал чужой файл, это видно по колонтитулу, имени файла и характеру ошибок.

Итоговая строка для сильного уровня

Если студент выполняет дополнительное задание, общее количество огнетушителей:

  • ОП-5: 2 + 2 = 4;
  • ОУ-3: 1;
  • ОП-10: 1;
  • Всего огнетушителей: 6 шт.

Пожарные краны в итог по огнетушителям не включаются. Если студент считает все первичные средства, то всего устройств: 8, но формулировка итога должна быть точной: «Всего огнетушителей — 6 шт.» или «Всего учтённых первичных средств — 8 шт.».

Критерии выставления оценки

Оценка Критерии
5 Выполнены все пункты чек-листа. Таблица структурирована, данные внесены верно, оформление аккуратное. Файл назван правильно.
4 Таблица выполнена верно, но есть 1–2 незначительные недоработки по форматированию.
3 Таблица создана, но есть существенные ошибки: пропущены данные, нет заголовков, не настроены границы, нарушено выравнивание, файл назван неправильно.
2 Таблица не создана, данные оформлены текстом, работа не сдана либо списана.

Методические указания

  • Главная цель — не просто вставить таблицу, а понять, как данные структурируются по столбцам.
  • Частая ошибка: студент делает слишком узкий столбец «Примечание», из-за чего таблица выходит за поля. Напомните про альбомную ориентацию и автоподбор ширины.
  • Проверяйте тип таблицы. Если студент напечатал текст через табуляцию, это не считается. Нужна именно таблица текстового процессора.
  • Выравнивание важно. Номера, количество и даты по центру, длинные тексты по левому краю. Это формирует культуру работы с данными.
  • Для слабой группы можно уменьшить количество столбцов до 5: №, наименование, место, количество, дата. Но для оценки «5» лучше требовать полный набор.
  • Для сильной группы добавьте итоговую строку и простую формулу суммирования.
  • Свяжите с профессией. Покажите, что такая таблица может быть приложением к акту проверки, журналу эксплуатации или докладу руководству.
