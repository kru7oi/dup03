Раздел 2 / Тема 2.2 / ПЗ 25

Сбор исходных данных для создания базы данных в MS Excel

Тема 2.2 Практическое занятие 1 ак. час ОК.01, ОК.02, ОК.04 · ДПК.3.1 · ПР.06

Цель занятия

Цель: подготовить структурированный массив данных в Excel, пригодный для использования в качестве простой реляционной базы данных, используя инструменты нормализации, ограничения ввода и автоматического расширения диапазонов.

Задачи занятия
  • понять принципы организации данных в табличном процессоре как в СУБД;
  • научиться разделять справочники и факты (нормализация);
  • освоить функцию «Проверка данных» для создания выпадающих списков;
  • применить инструмент «Умная таблица» для автоматической сортировки и фильтрации;
  • заполнить базу данных «Учет пожарных гидрантов» корректными значениями.
Формируемые компетенции и результаты
  • ОК.01 — организовывать хранение информации;
  • ОК.02 — использовать средства контроля качества данных;
  • ДПК.3.1 — вести учет материальных средств;
  • ПР.06 — создавать и наполнять базы данных.

Теоретический блок

1. Excel как база данных

Excel часто используют как легкую СУБД. Главное отличие от простого списка — наличие связей и ограничений.

  • Таблица фактов: хранит события (кто, где, когда проверил гидрант).
  • Таблица справочников: хранит постоянные данные (список улиц, типы гидрантов, ФИО инспекторов).

2. Нормализация данных

Нормализация — это устранение избыточности. Нельзя хранить адрес улицы в каждой строке журнала. Нужно хранить ID улицы или ссылку на справочник.

Пример ошибки Если в журнале написано «ул. Ленина» и «ул.Ленина» (без пробела), система посчитает это разными объектами. Решение: использовать выпадающий список, где варианты берутся из чистого справочника.

3. Проверка данных (Data Validation)

Инструмент позволяет запретить ввод любых значений, кроме разрешенных.

  • Тип «Список»: пользователь выбирает значение из выпадающего меню.
  • Тип «Число»: ограничение диапазона (например, диаметр гидранта не может быть отрицательным).
  • Тип «Дата»: проверка формата даты.

4. Функция «Умная таблица» (Format as Table)

Обычный диапазон ячеек — это статика. Умная таблица — это динамический объект.

  • Автоматически добавляет фильтры к каждому столбцу.
  • При добавлении новой строки внизу формулы и форматирование копируются автоматически.
  • Позволяет давать уникальные имена диапазону (например, tbl_Gidrants), которые удобно использовать в других формулах.

5. Учет ресурсов в МЧС

База данных гидрантов критически важна для планирования тушения.

  • Диспетчер должен знать: есть ли вода в ближайшем гидранте?
  • Инспектор должен фиксировать: дата последней проверки, состояние крышки, подъездные пути.
  • Ошибки в базе приводят к направлению расчетов на сухой гидрант.

Практическая работа

Цель работы: создать защищенную от ошибок ввода базу данных учета пожарных гидрантов.

Легенда: Учет пожарных гидрантов

Мы создадим файл с двумя листами:

  1. Лист «Справочник»: содержит неизменные данные (Улицы, Типы гидрантов, Статусы).
  2. Лист «Журнал»: содержит записи о конкретных гидрантах, привязанные к справочнику.

Шаг 1. Создание структуры таблиц

Лист 1: Справочник

Переименуйте Лист1 в Справочник. Заполните его следующим образом:

ЯчейкаСодержимое
A1Код улицы
B1Название улицы
D1Код типа
E1Тип гидранта
G1Код статуса
H1Статус исправности
A2:A6U-01, U-02, U-03, U-04, U-05
B2:B6Ленина, Садовая, Мира, Гагарина, Центральная
D2:D4T-1, T-2, T-3
E2:E4Наземный, Подземный, Колодец
G2:G4S-OK, S-BAD, S-REPAIR
H2:H4Исправен, Неисправен, В ремонте

Лист 2: Журнал

Создайте новый лист, переименуйте в Журнал. Заполните заголовки:

Шаг 2. Настройка выпадающих списков (Data Validation)

Теперь защитим столбцы C, E и H от ручного ввода.

Для столбца «Улица» (Column C)

  1. Выделите диапазон C2:C100 (на будущее).
  2. Вкладка «Данные» → «Проверка данных».
  3. В поле «Тип данных» выберите «Список».
  4. В поле «Источник» введите формулу ссылки на справочник:
    =Справочник!$B$2:$B$6
  5. Нажмите ОК. Теперь в столбце C появляется стрелочка выбора.

Для столбца «Тип гидранта» (Column E)

  1. Выделите E2:E100.
  2. Данные → Проверка данных → Список.
  3. Источник: =Справочник!$E$2:$E$4

Для столбца «Статус» (Column H)

  1. Выделите H2:H100.
  2. Данные → Проверка данных → Список.
  3. Источник: =Справочник!$H$2:$H$4

Для диаметра (Column F) — ограничение числами

  1. Выделите F2:F100.
  2. Данные → Проверка данных.
  3. Тип данных: «Целое».
  4. Условие: «больше или равно», Значение: 100.
  5. Во вкладке «Сообщение об ошибке» напишите: «Диаметр не может быть меньше 100 мм!»

Шаг 3. Преобразование в Умную таблицу

  1. Выделите весь диапазон заголовков и первых нескольких пустых строк данных: A1:I10.
  2. Нажмите Ctrl + T (или Вставка → Таблица).
  3. Убедитесь, что стоит галочка «Таблица с заголовками».
  4. Нажмите ОК.
  5. На вкладке «Конструктор таблиц» дайте таблице имя: tbl_Hydrants.
  6. Выберите стиль оформления (желательно нейтральный, официально-деловой).
Что произошло? Теперь, если вы введете данные в строку 11, Excel автоматически применит проверку данных и расширит форматирование таблицы. Вам не нужно каждый раз тянуть границы.

Шаг 4. Заполнение и проверка

Заполните 5-7 строк данными, используя ТОЛЬКО выпадающие списки.

  • Пример записи:
    № 1 | Г-101 | ул. Ленина | 10 | Наземный | 200 | 10.10.2026 | Исправен | Иванов И.И.

Тест на защиту:

  1. Попробуйте ввести в столбец «Улица» слово «Пушкина» (которого нет в справочнике). Excel выдаст ошибку.
  2. Попробуйте ввести в диаметр число 50. Excel выдаст предупреждение.

Критерии оценки

ОценкаКритерии
5Структура разделена правильно. Выпадающие списки работают и ссылаются на верные диапазоны. Умная таблица создана. Попытка ввести неверные данные блокируется системой.
4Списки сделаны, но ссылка идет на абсолютные координаты без имени листа (работает только если лист активен) или не настроена проверка для диаметра.
3Таблица есть, но данные вводятся вручную, защита не настроена. Или справочник и журнал находятся на одном листе.
2Файл не соответствует структуре БД, данные хаотичны.

Домашнее задание

Задание:

Создайте аналогичную базу данных для учета «Огнетушителей».

Лист «Справочник»: Марки (ОП-5, ОП-10, ОУ-3, ОУ-5), Типы заряда (Порошок, Углекислота, Воздушно-пенный).

Лист «Журнал»: Инвентарный №, Место установки, Марка (список), Тип заряда (список), Дата производства, Срок годности, Последний осмотр.

Обеспечьте проверку, что срок годности не может быть раньше даты производства (используйте формулу проверки или просто обратите внимание на логику).
