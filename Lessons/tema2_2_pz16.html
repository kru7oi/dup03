Раздел 2 / Тема 2.2 / ПЗ 22

Применение формул в MS Excel

Тема 2.2 Практическое занятие 1 ак. час ОК.01, ОК.02, ОК.04 · ДПК.3.1 · ПР.06

Цель занятия

Цель: освоить правила создания и редактирования формул в электронных таблицах MS Excel, научиться выполнять арифметические вычисления и использовать базовые статистические функции для обработки данных о ресурсах подразделения.

Задачи занятия
  • изучить синтаксис формул (обязательный знак «=»);
  • освоить операторы сложения, вычитания, умножения и деления;
  • разобрать относительные и абсолютные ссылки;
  • научиться использовать функции СУММ, СРЗНАЧ, МИН, МАКС;
  • рассчитать потребность в ГСМ и воде для условного тушения пожара.
Формируемые компетенции и результаты
  • ОК.01 — выбирать способы решения задач профессиональной деятельности;
  • ОК.02 — использовать информационные технологии для анализа данных;
  • ДПК.3.1 — работать с программным обеспечением подразделений;
  • ПР.06 — использовать электронные таблицы для обработки данных (вычисление суммы, среднего значения, максимума).

План занятия на 45 минут

Этап Время Содержание
I. Вводный инструктаж 0–5 мин Объяснение разницы между числом и формулой. Зачем нужны автоматические расчеты.
II. Теоретический блок 5–20 мин Синтаксис, операторы, ссылки ($), функции.
III. Практическая работа 20–40 мин Создание калькулятора расхода воды и топлива.
IV. Итоги 40–45 мин Проверка результатов, разбор ошибок, оценка.

Теоретический блок

1. Синтаксис формул

Любая формула в Excel начинается со знака равенства =. Без этого символа программа воспримет запись как обычный текст или число, но не выполнит вычисление.

Ошибка новичков Если вы напишете A1+B1, Excel покажет эту строку как текст. Нужно писать =A1+B1.

2. Операторы вычисления

Оператор Назначение Пример Результат
+ Сложение =A1+A2 Сумма значений ячеек A1 и A2
- Вычитание =A1-A2 Разность значений
* Умножение =A1*A2 Произведение значений
/ Деление =A1/A2 Частное значений
^ Возведение в степень =A1^2 Квадрат значения A1

3. Типы ссылок на ячейки

При копировании формул важно понимать, как меняются адреса ячеек.

Тип ссылки Запись Поведение при копировании Пример использования
Относительная A1 Адрес меняется относительно смещения Расчет итогов по каждой машине отдельно
Абсолютная $A$1 Адрес фиксируется, не меняется никогда Ставка налога или коэффициент расхода, который лежит в одной ячейке
Смешанная $A1 или A$1 Фиксируется только столбец или только строка Реже используется на базовом уровне
Горячая клавиша F4 Чтобы быстро добавить знаки доллара ($) к ссылке, выделите адрес в строке формул и нажмите F4. Повторное нажатие переключает типы фиксации.

4. Базовые функции

Функции — это готовые формулы для сложных расчетов. Их не нужно придумывать вручную.

Функция Синтаксис Назначение
СУММ =СУММ(A1:A10) Складывает все числа в диапазоне
СРЗНАЧ =СРЗНАЧ(B1:B5) Вычисляет среднее арифметическое значение
МИН =МИН(C1:C20) Находит наименьшее значение в списке
МАКС =МАКС(D1:D10) Находит наибольшее значение в списке

5. Формулы в работе специалиста пожарной безопасности

Расчеты в Excel применяются ежедневно:

  • Расход воды: определение объема воды, необходимого для тушения очага возгорания за определенное время, исходя из производительности стволов.
  • Расход ГСМ: планирование затрат топлива при переброске сил и средств на дальние расстояния.
  • Статистика пожаров: подсчет общего количества вызовов за месяц, выявление дня недели с максимальной нагрузкой (функция МАКС).
  • Инвентаризация: суммирование остатков огнетушителей, рукавов, боевой одежды по складам.

Практическая работа

Цель работы: создать файл расчета потребности в горюче-смазочных материалах (ГСМ) и воде для условного выезда караула.

Формат: индивидуальная работа за ПК.

Задание

  1. Откройте новый файл Excel.
  2. Введите заголовок в ячейку A1: Расчет ресурсов для тушения. Объедините ячейки A1:E1.
  3. Во второй строке (A2:E2) создайте шапку таблицы:
    • A2: № п/п
    • B2: Марка автомобиля
    • C2: Расстояние до объекта, км
    • D2: Расход топлива, л/100км
    • E2: Необходимо ГСМ, л
  4. Заполните данные для 3 автомобилей (строки 3–5):
    • 1 | АЦ-40 (5339) | 15 | 35 | (формула)
    • 2 | АЦ-32 (43118) | 22 | 40 | (формула)
    • 3 | ЛАВ-12 | 8 | 25 | (формула)
  5. В ячейку E3 введите формулу для расчета расхода топлива:
    =C3*D3/100
    (Расстояние умножаем на расход и делим на 100).
  6. Скопируйте формулу из E3 вниз в ячейки E4 и E5. Убедитесь, что результаты пересчитались автоматически.
  7. Добавьте строку «Итого» (строка 6):
    • A6: пусто
    • B6: ВСЕГО:
    • C6-E6: используйте функцию =СУММ() для подсчета общих километров и литров топлива.
  8. Выделите диапазон B6:F6 и сделайте его полужирным.
  9. Сохраните файл как ФамилияИО_группа_ПЗ22.xlsx.

Исходные данные для проверки

Ваши результаты в столбце E должны быть следующими:

  • Для АЦ-40: 5,25 л
  • Для АЦ-32: 8,8 л
  • Для ЛАВ-12: 2,0 л
  • Итого ГСМ: 16,05 л

Критерии оценки

ОценкаКритерии
5Все формулы составлены верно. Использовано автозаполнение. Функция СУММ применена правильно. Данные совпадают с эталоном. Файл назван корректно.
