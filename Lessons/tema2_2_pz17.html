Составление отчёта в MS Excel

Тема 2.2 Практическое занятие 1 ак. час ОК.01, ОК.02, ОК.04 · ДПК.3.1 · ПР.06

Цель занятия

Цель: научиться формировать сводные отчеты на основе массива данных, используя инструменты сортировки, фильтрации и настройки области печати для подготовки документа к сдаче руководству.

Задачи занятия
  • понять структуру типового отчета (шапка, тело, итоги);
  • освоить сортировку данных по нескольким признакам;
  • научиться фильтровать записи (например, оставить только нарушения по эвакуации);
  • отработать настройку параметров страницы для качественной печати;
  • составить отчет о выявленных нарушениях требований пожарной безопасности за квартал.
Формируемые компетенции и результаты
  • ОК.01 — выбирать методы анализа информации;
  • ОК.02 — использовать IT для представления результатов деятельности;
  • ДПК.3.1 — работать с ПО подразделений;
  • ПР.06 — создавать структурированные документы, выполнять сортировку и поиск записей.

План занятия на 45 минут

Этап Время Содержание

Теоретический блок

1. Что такое отчет в Excel

Отчет — это документ, содержащий систематизированные данные, выводы и рекомендации. В Excel отчет обычно включает:

  • Заголовок (кто составил, кому, период);
  • Табличную часть с данными;
  • Итоговые показатели (суммы, проценты);
  • Примечания или комментарии.

2. Структура отчета

Часть отчета Содержание Инструменты Excel
Шапка Название организации, вид документа, дата Объединение ячеек, жирный шрифт, центрирование
Тело Перечень объектов, нарушений, сроков Табличные стили, границы, чередование цветов строк
Итоги Всего нарушений, устранено, просрочено Функции СУММ, СЧЁТЕСЛИ, подводящие итоги
Подвал Подпись исполнителя, должность Выравнивание по правому краю, рамка для подписи

3. Сортировка данных

Сортировка упорядочивает строки таблицы по значению одного или нескольких столбцов.

  • По возрастанию: А→Я, 0→9, Ранняя дата→Поздняя.
  • По убыванию: Я→А, 9→0, Поздняя дата→Ранняя.
Пример: В отчете о нарушениях удобно сначала отсортировать список по дате выявления (чтобы свежие были сверху), а затем по степени тяжести (грубые нарушения первыми).

4. Фильтрация данных

Фильтр позволяет скрыть ненужные строки и оставить только те, которые соответствуют условию.

  1. Выделите шапку таблицы.
  2. Вкладка «Данные» → кнопка «Фильтр» (значок воронки).
  3. В появившихся выпадающих списках выберите нужные значения.
Важно При фильтрации скрываются целые строки. Будьте осторожны, чтобы случайно не удалить видимые данные, так как скрытые останутся в файле.

5. Настройка печати

Отчет должен выглядеть аккуратно на бумаге. Основные настройки:

  • Ориентация: Альбомная (для широких таблиц) или Книжная.
  • Поля: Узкие или Средние.
  • Масштаб: «Вписать лист на одну страницу» или задать процент.
  • Закрепление областей: Чтобы шапка таблицы повторялась на каждой странице (Макет страницы → Закрепить области).

6. Виды отчетов в МЧС

  • Отчет о состоянии противопожарной защиты объекта: перечень зданий, год постройки, класс функциональной опасности, наличие сигнализации.
  • Справка о результатах проверки: дата, адрес, выявленные нарушения, срок устранения, ответственные лица.
  • Журнал учета вызовов: время поступления, адрес, характер ЧС, силы и средства, время прибытия, время ликвидации.
  • Статистический сборник: количество пожаров по районам города за год, динамика роста/снижения.

Практическая работа

Цель работы: сформировать печатную версию отчета о выявленных нарушениях требований пожарной безопасности.

Формат: индивидуальная работа за ПК.

Задание

  1. Создайте новый файл Excel.
  2. Введите исходные данные (см. раздел «Исходные данные») в диапазон A1:F10.
  3. Оформите шапку отчета:
    • Вставьте две пустые строки над таблицей.
    • В A1: ГБПОУ ТПСК им. В.М. Максимчука (по центру, полужирный).
    • В A2: СПРАВКА о результатах проверки соблюдения требований пожарной безопасности (по центру, капсом).
    • В A3: за октябрь 2026 года (по центру, курсив).
  4. Отформатируйте саму таблицу:
    • Установите границы для всех ячеек данных.
    • Выделите строку заголовков (теперь это строка 5, так как мы добавили 3 строки сверху) и сделайте её полужирной с серой заливкой.
    • Выровняйте текст в столбцах «Дата», «Объект» по левому краю, «Нарушение» по ширине, «Срок» по центру.
  5. Примените сортировку:
    • Отсортируйте таблицу по столбцу «Дата» (от старых к новым).
    • Затем добавьте уровень сортировки по столбцу «Объект» (по алфавиту).
  6. Настройте печать:
    • Вкладка «Макет страницы».
    • Ориентация: Альбомная.
    • Поля: Узкие.
    • Закрепить области: Выберите ячейку A6 (начало тела таблицы после шапки), нажмите Закрепить области → Закрепить верхние строки. Это гарантирует, что названия столбцов будут видны на всех страницах.
    • Проверьте результат через Файл → Печать → Предварительный просмотр.
  7. Сохраните файл как ФамилияИО_группа_ПЗ23.xlsx.

Критерии оценки
