Раздел 2 / Тема 2.2 / ПЗ 26

Создание формы для ввода данных в Эксель

Тема 2.2 Практическое занятие 1 ак. час ОК.01, ОК.02, ОК.04 · ДПК.3.1 · ПР.06

Цель занятия

Цель: научиться создавать форму ввода данных в электронной таблице, использовать справочники, проверку данных, встроенную форму Эксель и собственную карточку ввода для заполнения реестра пожарно-технических средств.

Задачи занятия
  • понять отличие формы ввода от обычного заполнения таблицы;
  • создать лист справочников для единообразия данных;
  • преобразовать диапазон в таблицу и назвать её;
  • настроить проверку данных для числовых, датированных и списочных полей;
  • заполнить реестр из 10 записей с помощью встроенной формы;
  • создать собственную карточку ввода с обязательными полями;
  • защитить лист формы от случайного изменения служебных ячеек;
  • сохранить файл в формате книги Эксель.
Формируемые компетенции и результаты
  • ОК.01 — выбирать способы решения профессиональных задач;
  • ОК.02 — использовать информационные технологии для сбора и обработки данных;
  • ОК.04 — организовывать самостоятельную работу и контролировать результат;
  • ДПК.3.1 — работать с программным обеспечением, установленным в подразделениях;
  • ПР.06 — создавать структурированные базы данных, наполнять их, выполнять поиск и сортировку записей.

План занятия на 45 минут

  • Объяснение цели формы ввода. Почему ручной ввод в таблицу часто приводит к ошибкам.
    • Этап Время Содержание
    I. Вводный инструктаж 0–5 мин
    II. Теоретический блок 5–15 мин Форма ввода, справочники, проверка данных, встроенная форма, карточка ввода, защита листа.
    III. Практическая часть 1 15–25 мин Создание листов «Справочники» и «Реестр», настройка таблицы и проверки данных.
    IV. Практическая часть 2 25–35 мин Заполнение 10 записей через встроенную форму Эксель.
    V. Практическая часть 3 35–42 мин Создание собственной карточки ввода, проверка заполнения, защита листа.
    VI. Итоги 42–45 мин Проверка файлов, разбор ошибок, выставление оценки, домашнее задание.

    Теоретический блок

    1. Что такое форма ввода данных

    Форма ввода данных — это интерфейс, который помогает пользователю заполнять таблицу или базу данных по очереди, не работая напрямую со всеми ячейками листа.

    Если специалист вводит данные прямо в таблицу, он может:

    • перепутать строку и столбец;
    • вписать текст вместо числа;
    • написать фамилию ответственного по-разному в разных записях;
    • пропустить обязательное поле;
    • исправить соседнюю запись случайным нажатием клавиш.

    Форма ввода снижает эти риски. Она показывает только те поля, которые нужно заполнить, и может ограничивать допустимые значения.

    Профессиональный смысл В учёте пожарно-технического вооружения, гидрантов, огнетушителей, инструктажей и объектов проверки важна не только скорость ввода, но и единообразие данных. Одинаково заполненные справочники позволяют позже строить отчёты, фильтры, сортировку и макросы.

    2. Встроенная форма Эксель

    В Эксель есть служебная команда «Форма...». Она автоматически создаёт окно ввода по заголовкам таблицы.

    Преимущества встроенной формы:

    • не нужно программировать кнопки;
    • поля соответствуют столбцам таблицы;
    • можно добавлять, удалять и искать записи;
    • удобно вводить большое количество однотипных записей.

    В современных версиях Эксель эта команда может быть скрыта. Её нужно добавить на панель быстрого доступа или на вкладку через параметры программы.

    Важно Встроенная форма работает с таблицей или диапазоном, у которого есть заголовки. Если заголовков нет, форма будет неудобной или может отобразить поля как «Столбец 1», «Столбец 2».

    3. Собственная карточка ввода

    Кроме встроенной формы, можно создать собственную карточку ввода на отдельном листе. Это более гибкий способ.

    На карточке размещают:

    • надписи полей;
    • ячейки для ввода;
    • выпадающие списки;
    • служебную проверку заполненности;
    • кнопки, если позже будут добавлены макросы;
    • защиту листа, чтобы нельзя было случайно изменить надписи.

    Собственная карточка особенно полезна, когда нужно подготовить интерфейс для будущей автоматизации. На следующем занятии к такой форме будут добавлены макросы.

    4. Проверка данных

    Проверка данных — это ограничение, которое разрешает вводить только допустимые значения.

    Тип ограничения Пример Назначение
    Список Тип средства, состояние, ответственный Не допустить разных написаний одних и тех же значений
    Целое число Количество, штук Запретить текст, дробные значения и отрицательные числа
    Дата Дата ввода, дата следующей проверки Обеспечить корректный формат даты
    Условие Дата следующей проверки позже даты ввода Проверить логическую связь полей

    5. Защита листа

    Защита листа нужна, чтобы пользователь мог заполнять только предназначенные для этого ячейки.

    Обычно поступают так:

    1. Снимают защиту с ячеек ввода.
    2. Оставляют защищаемыми надписи, формулы, служебные поля.
    3. Включают защиту листа.
    Полезное правило Не нужно защищать весь лист, если пользователь должен вводить данные. Нужно открыть только те ячейки, которые являются полями формы.

    6. Формы в профессиональной деятельности

    Формы ввода применяются при учёте:

    • огнетушителей, пожарных кранов, гидрантов, пожарных щитов;
    • объектов с массовым пребыванием людей;
    • инструктажей по пожарной безопасности;
    • нарушений и сроков их устранения;
    • дежурств личного состава;
    • вызовов пожарно-спасательных подразделений;
    • средств индивидуальной защиты и боевой одежды.

    Хорошо настроенная форма позволяет позже автоматически получать отчёты, находить просроченные проверки и передавать данные руководству.

    Практическая работа

    Цель работы: создать файл с реестром пожарно-технических средств, справочниками, встроенной формой ввода и собственной карточкой ввода.

    Формат: индивидуальная работа за персональным компьютером.

    Тема учёта Будем вести реестр первичных средств пожаротушения и пожарного оборудования условного объекта.

    Шаг 1. Лист справочников

    Создайте новый файл Эксель. Первый лист переименуйте в Справочники.

    Заполните лист следующим образом.

    Ячейка Значение
    A1Тип средства
    A2Огнетушитель порошковый
    A3Огнетушитель углекислотный
    A4Пожарный кран
    A5Гидрант
    A6Щит пожарный
    B1Состояние
    B2Исправно
    B3Требует ремонта
    B4Неисправно
    B5Списано
    D1Ответственный
    D2Иванов И. И.
    D3Петров А. С.
    D4Сидорова М. В.
    D5Кузнецов П. П.
    D6Морозова Е. В.
    D7Волков С. Н.
    Зачем нужны справочники Они обеспечивают единое написание значений. Если в реестре будет «Иванов И.И.», «Иванов И. И.» и «иванов», фильтрация и отчёты будут работать неправильно.

    Шаг 2. Реестр и таблица

    Создайте новый лист и переименуйте его в Реестр.

    Введите заголовки в диапазон A1:J1.

    Ячейка Заголовок
    A1№ п/п
    B1Инвентарный номер
    C1Наименование средства
    D1Тип средства
    E1Место установки
    F1Количество, шт.
    G1Дата ввода в эксплуатацию
    H1Следующая проверка
    I1Ответственный
    J1Состояние

    Преобразование в таблицу

    1. Выделите диапазон A1:J2. Строка 2 пока должна остаться пустой, но входить в таблицу.
    2. На вкладке «Главная» нажмите «Форматировать как таблицу».
    3. Выберите любой стиль, но не слишком яркий.
    4. Подтвердите, что таблица имеет заголовки.
    5. На вкладке «Конструктор таблицы» в поле «Имя таблицы» введите: tblРеестр.

    Настройка проверки данных

    Выделите диапазон D2:D1000.

    1. Откройте вкладку «Данные».
    2. Нажмите «Проверка данных».
    3. В поле «Тип данных» выберите «Список».
    4. В поле «Источник» введите:
      =Справочники!$A$2:$A$6
    5. На вкладке «Сообщение об ошибке» укажите заголовок «Недопустимый тип средства» и текст «Выберите значение из списка».
    6. Нажмите «ОК».

    Выделите диапазон J2:J1000 и настройте список:

    =Справочники!$B$2:$B$5

    Выделите диапазон I2:I1000 и настройте список:

    =Справочники!$D$2:$D$7

    Выделите диапазон F2:F1000 и настройте целое число:

    • Тип данных: «Целое»;
    • Условие: «больше или равно»;
    • Минимальное значение: 1.

    Выделите диапазоны G2:G1000 и H2:H1000 и настройте дату:

    • Тип данных: «Дата»;
    • Условие: «между»;
    • Начальная дата: 01.01.2020;
    • Конечная дата: 31.12.2100.
    Проверьте себя Попробуйте в ячейку D2 ввести слово «Тест». Эксель должен отклонить ввод. Попробуйте в F2 ввести 0. Эксель также должен выдать ошибку.

    Шаг 3. Встроенная форма и заполнение 10 записей

    Добавление команды «Форма...»

    Если команда «Форма...» не видна, добавьте её.

    1. Откройте «Файл» → «Параметры».
    2. Перейдите в раздел «Настройка ленты» или «Панель быстрого доступа».
    3. В списке «Выбрать команды из» укажите «Все команды».
    4. Найдите команду «Форма...».
    5. Добавьте её на панель быстрого доступа или в удобную группу.
    6. Нажмите «ОК».

    Заполнение реестра

    Выделите любую ячейку таблицы tblРеестр и откройте команду «Форма...».

    В открывшемся окне заполните 10 записей. Первую запись можно ввести в уже существующую пустую строку таблицы, затем нажимайте «Добавить» для следующих записей.

    Данные для заполнения
    1. 1 | ОГ-001 | Огнетушитель порошковый ОП-5 | Огнетушитель порошковый | 1 этаж, коридор у входа | 2 | 10.09.2025 | 10.03.2026 | Иванов И. И. | Исправно

    5. 5 | ЩП-01 | Пожарный щит ЩП-А | Щит пожарный | 1 этаж, пост охраны | 1 | 08.09.2025 | 08.03.2026 | Морозова Е. В. | Исправно
    6. 6 | ОГ-003 | Огнетушитель порошковый ОП-10 | Огнетушитель порошковый | Котельная | 1 | 15.09.2025 | 15.03.2026 | Волков С. Н. | Неисправно

    После заполнения проверьте, что в листе «Реестр» заполнены строки A2:J11.

    Важно Не пропускайте поля. Если встроенная форма не позволяет выбрать значение из списка, значит, проверка данных настроена на другом диапазоне. Исправьте источник списка.

    Шаг 4. Собственная карточка ввода

    Создайте новый лист и переименуйте его в Форма.

    Этот лист будет визуальной карточкой. На следующем занятии к ней будут добавлены макросы.

    Разметка карточки

    Ячейка Содержимое
    B1Карточка ввода записи
    B3Инвентарный номер
    C3 поле для ввода
    B4Наименование средства
    C4 поле для ввода
    B5Тип средства
    C5 поле для выбора
    B6Место установки
    C6 поле для ввода
    B7Количество, шт.
    C7 поле для ввода числа
    B8Дата ввода в эксплуатацию
    C8 поле для даты
    B9Следующая проверка
    C9 поле для даты
    B10Ответственный
    C10 поле для выбора
    B11Состояние
    C11 поле для выбора
    B2Служебная проверка
    C2 формула проверки заполненности

    Оформите заголовок в ячейке B1: полужирный шрифт, размер 16, выравнивание по центру. Объедините ячейки B1:F1, если это удобно.

    Надписи в столбце B сделайте полужирными. Столбец C расширьте так, чтобы в него помещались длинные значения.

    Формула проверки заполненности

    В ячейку C2 введите формулу:

    Формула служебной проверки 
    =ЕСЛИ(И(C3<>"";C4<>"";C5<>"";C6<>"";C7<>"";C8<>"";C9<>"";C10<>"";C11<>"");"Все поля заполнены";"Заполните обязательные поля")

    Если хотя бы одно поле пустое, форма должна показывать текст «Заполните обязательные поля».

    Проверка данных на карточке

    Настройте проверку данных для ячеек формы.

    Ячейка Тип проверки Источник или условие
    C5 Список =Справочники!$A$2:$A$6
    C10 Список =Справочники!$D$2:$D$7
    C11 Список =Справочники!$B$2:$B$5
    C7 Целое больше или равно 1
    C8 Дата между 01.01.2020 и 31.12.2100
    C9 Дата между 01.01.2020 и 31.12.2100

    Условное форматирование

    Выделите диапазон C3:C11.

    1. Откройте «Главная» → «Условное форматирование» → «Создать правило».
    2. Выберите «Использовать формулу для определения форматируемых ячеек».
    3. Введите формулу:
      =И(C3<>"";СЧЁТЕСЛИ(Реестр!$B$2:$B$1000;C3)>0)
    4. Установите красную заливку для дубликата инвентарного номера.
    Примечание Эта формула подсвечивает случай, если введённый инвентарный номер уже есть в реестре. Для остальных полей можно настроить подсветку пустых обязательных ячеек.

    Шаг 5. Проверка и защита

    Проверка работы формы

    Выполните пробный ввод в карточке:

    • в C3 введите ОГ-011;
    • в C4 введите Огнетушитель порошковый ОП-5;
    • в C5 выберите «Огнетушитель порошковый»;
    • в C6 введите 1 этаж, столовая;
    • в C7 введите 2;
    • в C8 введите 20.10.2026;
    • в C9 введите 20.04.2027;
    • в C10 выберите ответственного;
    • в C11 выберите «Исправно».

    Проверьте, что в C2 появилось сообщение «Все поля заполнены».

    Теперь очистите одно поле и убедитесь, что сообщение изменилось.

    Защита листа формы

    1. Выделите ячейки C3:C11.
    2. Откройте «Главная» → «Формат» → «Формат ячеек».
    3. Перейдите на вкладку «Защита».
    4. Снимите отметку «Защищаемая ячейка».
    5. Нажмите «ОК».
    6. Перейдите на вкладку «Рецензирование».
    7. Нажмите «Защитить лист».
    8. Оставьте защиту без пароля или задайте простой пароль, который сообщите преподавателю.
    9. Подтвердите защиту.
    Важно для следующего занятия Если на листе будут размещаться кнопки с макросами, при защите листа нужно разрешить работу с объектами. Иначе кнопки могут стать недоступными.

    Сохранение файла

    Сохраните файл под именем:

    ФамилияИО_группа_ПЗ26.xlsx
