Раздел 1 · Тема 1.1 · Практическое занятие 3

Использование информационных ресурсов для хранения информации

📚 Вид: Практическое занятие (ПЗ) ⏱️ Объём: 1 ак. час (45 мин) 📍 Формат: очный

🎯 Цели и задачи занятия

🎯 Цель:

Сформировать у обучающихся навыки выбора и использования информационных ресурсов для хранения профессиональной информации с учетом требований к безопасности, доступности, объему данных и нормативным требованиям пожарной безопасности.

Формируемые результаты (согласно РП):

ОК.01 ОК.02 ДПК.3.1 ЛР.03 ЦО.06 МР.01 ПР.01–07

🔤 Аббревиатуры занятия

Ключевые сокращения, используемые в материале:
  • ИР – Информационный ресурс
  • БД – База данных
  • СУБД – Система управления базами данных
  • ОС – Операционная система
  • ФС – Файловая система
  • ПДн – Персональные данные
  • ФЗ-152 – Федеральный закон «О персональных данных»
  • НСД – Несанкционированный доступ
  • РБД – Реляционная база данных
  • РП – Рабочая папка

📖 Теоретический блок

1. Понятие информационного ресурса для хранения

Информационный ресурс для хранения — это совокупность технических средств, программного обеспечения и организационных мер, предназначенных для сохранения, структурирования и обеспечения доступа к информации в течение заданного времени.

2. Классификация ресурсов хранения

Тип ресурса Характеристика Примеры Применение в ПС
Локальные Хранение на одном устройстве или в локальной сети Жесткий диск ПК, сетевое хранилище (NAS), USB-флеш-накопитель АРМ инспектора ГПН, хранение личных документов
Сетевые Хранение на серверах организации с доступом по сети Файловый сервер, корпоративное облако МЧС Обмен документами между подразделениями гарнизона
Облачные Хранение на удаленных серверах провайдера Яндекс.Диск, Облако Mail.ru, Google Drive Резервное копирование, удаленный доступ к документам
Базы данных Структурированное хранение с возможностью запросов MS Access, MySQL, АИС «Электронный инспектор» Реестр объектов защиты, статистика пожаров

3. Требования к хранению профессиональной информации

При выборе ресурса хранения специалист пожарной безопасности должен учитывать:

  • Конфиденциальность: персональные данные граждан, служебная информация требуют защиты по ФЗ-152 и ведомственным приказам
  • Доступность: критические данные (карты выезда, планы зданий) должны быть доступны 24/7
  • Целостность: защита от несанкционированного изменения (особенно важно для протоколов и предписаний)
  • Резервное копирование: наличие нескольких копий в разных местах
  • Сроки хранения: некоторые документы (акты проверок, предписания) хранятся установленный срок

4. Файловая организация

Эффективное хранение требует логичной структуры папок. Рекомендуемая структура для специалиста ПС:

  • 📁 Документы/
    • 📁 Нормативные акты/ (ФЗ, СП, ГОСТ)
    • 📁 Приказы МЧС/
  • 📁 Рабочие материалы/
    • 📁 Проверки 2026/
    • 📁 Пожары/
    • 📁 Отчеты/
  • 📁 Архив/ (завершенные дела)
  • 📁 Временные файлы/ (для черновиков)

💼 Практическая работа

🔹 Кейс №1: Выбор ресурса хранения

Определите оптимальный тип ресурса хранения для каждой из профессиональных ситуаций. Обоснуйте выбор.

№ Ситуация Тип ресурса Обоснование
1 Инспектор ГПН хранит базу данных проверенных объектов за 5 лет
2 Диспетчер ПСГ должен иметь доступ к картам выезда с любого устройства в части и дома
3 Начальник караула ведет личный журнал учета ПТВ
4 Аналитик МЧС обрабатывает статистику пожаров за 10 лет (100 ГБ данных)
5 РТП на месте ЧС должен быстро получить план здания из базы

🔹 Кейс №2: Создание структуры папок

Создайте логичную структуру папок для инспектора ГПН, который ведет следующие виды деятельности:

  • Плановые и внеплановые проверки объектов
  • Ведение реестра объектов защиты
  • Работа с обращениями граждан
  • Подготовка отчетов и статистики
  • Изучение нормативных актов

Нарисуйте схему структуры папок в тетради или на компьютере. Укажите, какие файлы будут храниться в каждой папке.

📝 Домашнее задание

  • Папки для учебных материалов по каждому семестру
