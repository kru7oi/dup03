Раздел 1 / Тема 1.1 / ПЗ 3

Использование информационных ресурсов для хранения информации

Тема 1.1 Практическое занятие 1 ак. час ОК.01, ОК.02 · ДПК.3.1 · ПР.01–07

Цель занятия

Сформировать навыки выбора и использования информационных ресурсов для хранения профессиональной информации с учетом требований к безопасности, доступности, объему данных и нормативным требованиям пожарной безопасности.

Формируемые компетенции:
  • ОК.01 — выбирать способы решения задач профессиональной деятельности;
  • ОК.02 — использовать современные средства поиска, анализа и интерпретации информации;
  • ПР.01 — владеть понятиями «информационный ресурс», «база данных», «файловая система».

План занятия (45 минут)

  1. 0–3 мин. Вводный инструктаж: постановка задачи, актуальность темы.
  2. 3–15 мин. Теоретический блок: виды ресурсов хранения, классификация, требования.
  3. 15–35 мин. Практическая работа: три кейса по выбору и организации хранения.
  4. 35–45 мин. Защита результатов, обсуждение, домашнее задание.

Теоретический блок

1. Понятие информационного ресурса для хранения

Информационный ресурс для хранения — это совокупность технических средств, программного обеспечения и организационных мер, предназначенных для сохранения, структурирования и обеспечения доступа к информации в течение заданного времени.

2. Классификация ресурсов хранения

Тип ресурса Характеристика Примеры Применение в ПС
Локальные Хранение на одном устройстве или в локальной сети Жесткий диск ПК, NAS, USB-флешка АРМ инспектора ГПН, личные документы
Сетевые Хранение на серверах организации с доступом по сети Файловый сервер, корпоративное облако МЧС Обмен документами между подразделениями
Облачные Хранение на удаленных серверах провайдера Яндекс.Диск, Облако Mail.ru, Google Drive Резервное копирование, удаленный доступ
Базы данных Структурированное хранение с возможностью запросов MS Access, MySQL, АИС «Электронный инспектор» Реестр объектов защиты, статистика пожаров

3. Требования к хранению профессиональной информации

При выборе ресурса специалист должен учитывать:

  • Конфиденциальность: защита персональных данных (ФЗ-152) и служебной тайны;
  • Доступность: критические данные должны быть доступны круглосуточно;
  • Целостность: защита от несанкционированного изменения;
  • Резервное копирование: наличие нескольких копий в разных местах;
  • Сроки хранения: соответствие номенклатуре дел.
Важно Хранение служебной документации, содержащей персональные данные граждан, в публичных зарубежных облачных сервисах (Google Drive, Dropbox) запрещено требованиями законодательства РФ о защите персональных данных.

Практическая работа

Выполните три кейса в тетради или файле .docx.

Кейс №1: Выбор ресурса хранения

Определите оптимальный тип ресурса хранения для каждой ситуации и обоснуйте выбор.

№ Ситуация Тип ресурса Обоснование
1 Инспектор ГПН хранит базу данных проверенных объектов за 5 лет
2 Диспетчер ПСГ должен иметь доступ к картам выезда с любого устройства в части и дома
3 Начальник караула ведет личный журнал учета ПТВ
4 Аналитик МЧС обрабатывает статистику пожаров за 10 лет (100 ГБ данных)
5 РТП на месте ЧС должен быстро получить план здания из базы

Кейс №2: Создание структуры папок

Разработайте логичную структуру папок для инспектора ГПН, ведущего следующие виды деятельности:

  • Плановые и внеплановые проверки объектов;
  • Ведение реестра объектов защиты;
  • Работа с обращениями граждан;
  • Подготовка отчетов и статистики;
  • Изучение нормативных актов.

Нарисуйте схему структуры папок (в виде дерева) в тетради или файле. Укажите, какие файлы будут храниться в каждой папке.

Домашнее задание

Задание:

Создайте на своем компьютере (или в разрешенном облачном сервисе) структуру папок для студента специальности «Пожарная безопасность». Структура должна включать:

  • Папки для учебных материалов по каждому семестру;
  • Папку для нормативных документов (ФЗ, СП, ГОСТ);
  • Папку для практических работ;
  • Папку для курсовых/дипломных проектов;
  • Архив за прошлые годы.

Сделайте скриншот структуры и подготовьте краткое описание (3–4 предложения), почему вы выбрали именно такую организацию.
