Раздел 1 / Тема 1.1 / ПЗ 1

Проведение анализа АСУ различного назначения. Варианты использования АСУ

Тема 1.1 Практическое занятие 1 ак. час ОК.01, ОК.02 · ДПК.3.1 · ПР.01–07

Цель занятия

Научиться проводить структурный анализ автоматизированных систем управления (АСУ) различного назначения, определять их тип, масштаб, состав обеспечения и варианты применения в профессиональной деятельности специалиста пожарной безопасности.

Формируемые компетенции:
  • ОК.01 — выбирать способы решения задач профессиональной деятельности;
  • ДПК.3.1 — работать с программным обеспечением, установленным в ПС;
  • ПР.01 — владеть понятиями «система», «информационная система», «система управления».

Ключевые сокращения

Для понимания материала необходимо знать следующие аббревиатуры:

План занятия (45 минут)

  1. 0–5 мин. Вводный инструктаж: постановка задачи, объяснение алгоритма анализа, деление на группы.
  2. 5–25 мин. Самостоятельная работа в группах по карточкам.
  3. 25–40 мин. Защита результатов, обсуждение, заполнение сводной таблицы.
  4. 40–45 мин. Подведение итогов, домашнее задание.

Алгоритм анализа АСУ

Для каждой системы необходимо определить параметры из таблицы ниже. Эти данные станут основой для заполнения аналитической карты.

№ Параметр анализа Что нужно определить
1Полное наименованиеОфициальное название и аббревиатура.
2НазначениеКакую задачу решает? Для кого предназначена?
3МасштабЛокальная / Ведомственная / Государственная.
4Тип обработкиСправочная / Решающая (управляющая) / Экспертная.

6Виды обеспеченияПримеры тех., прог., инфо. обеспечения.

Карточки для анализа

Изучите описания реальных АСУ МЧС России.

Карточка №1. АИС «Электронный инспектор»

Автоматизированная информационная система для органов государственного пожарного надзора (ГПН). Обеспечивает ведение реестра объектов защиты, планирование проверок (риск-ориентированный подход), формирование предписаний и отчётности. Используется инспекторами ГПН территориальных органов.

Карточка №2. АС ОКСИОН

Общероссийская комплексная система информирования и оповещения населения в местах массового пребывания людей. Включает уличные терминалы с экранами и громкоговорителями на вокзалах, в аэропортах, ТЦ. Управление осуществляется из ситуационных центров МЧС круглосуточно.

Карточка №3. Система-112

Единый номер вызова экстренных оперативных служб. Обеспечивает приём вызовов, автоматическое определение местоположения звонящего, маршрутизацию в соответствующую службу (пожарные, полиция, скорая) и контроль времени реагирования. Базируется в ЕДДС муниципалитетов.

Карточка №4. ИАС «Космос-МЧС»

Информационно-аналитическая система космического мониторинга для обнаружения и контроля ЧС по данным дистанционного зондирования Земли (ДЗЗ). Выявляет очаги природных пожаров, контролирует паводки, оценивает масштабы разрушений. Данные передаются в НЦУКС.

Вопросы для обсуждения

  1. Какая из четырёх систем наиболее важна на этапе предотвращения ЧС? Почему?
  2. Какая система работает непосредственно в момент возникновения ЧС и спасает жизни?
  3. Могут ли эти системы взаимодействовать друг с другом? Приведите пример цепочки: обнаружение → оповещение → реагирование.

Домашнее задание

Задание:

Самостоятельно найти информацию об одной АСУ, используемой в пожарной охране или МЧС России, которая не была рассмотрена на занятии (например, АРМ руководителя тушения пожара, системы автоматического пожаротушения, интегрированные с АСУ здания).

Заполнить для неё аналитическую карту по тому же шаблону (7 параметров). Указать источник информации.
