Раздел 1 / Тема 1.2 / ПЗ 8

Проведение оценки технических характеристик процессора ПК

Тема 1.2 Практическое занятие 1 ак. час ОК.02 · ДПК.3.1 · МР.03 · ПР.02

Цель занятия

Научиться читать спецификации центральных процессоров, понимать влияние количества ядер, частоты и кэш-памяти на производительность компьютера и выбирать процессор под конкретные задачи специалиста пожарной безопасности.

Формируемые компетенции:
  • ОК.02 — использовать современные средства поиска и анализа информации;
  • ДПК.3.1 — работать с программным обеспечением и аппаратными средствами ПС;
  • ПР.02 — понимать принципы устройства и функционирования современных компьютеров.

План занятия (45 минут)

  1. 0–5 мин. Вводный инструктаж: почему «i7 старого поколения» может быть слабее «i3 нового»?
  2. 5–20 мин. Теория: структура процессора, влияние ядер и частоты на работу ПО МЧС.
  3. 20–35 мин. Практическая работа: анализ характеристик и подбор ЦП под задачи.
  4. 35–45 мин. Проверка результатов, обсуждение, домашнее задание.

Теоретический блок: как работает процессор

1. Количество ядер и потоков

Современные программы редко используют одно ядро. Операционная система распределяет задачи между всеми доступными блоками.

  • Одноядерные процессы: простые скрипты, старые версии некоторых ведомственных баз данных.
  • Многоядерные процессы: рендеринг видео с места ЧС, распаковка архивов доказательств, работа в браузере с десятками вкладок, компиляция кода.
Пример из практики Инспектору ГПН достаточно 4 ядер для комфортной работы Word + Excel + Браузер. Аналитику, обрабатывающему большие массивы статистики пожаров, нужно 8–16 ядер для ускорения расчетов в Python или SQL.

2. Тактовая частота и IPC

Частота (ГГц) показывает, насколько быстро ядро выполняет команды. Однако высокая частота бесполезна, если архитектура неэффективна (низкий IPC).

  • Высокая частота: важна для игр и приложений, зависящих от одного потока (например, некоторые модули AutoCAD).
  • Высокий IPC: новая архитектура делает больше полезной работы за один такт. Процессор 3.5 ГГц нового поколения может быть быстрее процессора 4.0 ГГц прошлого поколения.

3. Кэш-память

Кэш хранит самые нужные данные рядом с ядром, чтобы не ждать обращения к медленной оперативной памяти.

  • L1: самый быстрый, маленький (~32–64 КБ на ядро).
  • L2: средний (~256–512 КБ на ядро).
  • L3: общий для всех ядер (~8–32 МБ). Большой L3 критичен для работы с базами данных и сложными моделями.

Ключевые параметры оценки ЦП

Параметр На что влияет Когда важен в ПС
Ядра / Потоки Многозадачность, параллельные вычисления Работа с тяжелыми файлами, виртуализация, обработка видео.
Базовая / Турбо-частота Скорость одиночных задач Открытие документов, отзывчивость интерфейса ОС.
Объем L3 кэша Быстрый доступ к данным Серверы БД, сложные расчеты рисков.
TDP (Вт) Тепловыделение и энергопотребление Выбор системы охлаждения, автономность ноутбука РТП.
Интегрированная графика Возможность вывода изображения без дискретной видеокарты Экономия бюджета на офисных ПК инспекторов.

Задание 2: Выбор процессора под профессиональную задачу

Определите, какой из трех процессоров оптимален для каждой роли. Учтите баланс цены, производительности и энергоемкости.

Роль / Задача Выбранный ЦП Обоснование
1. АРМ инспектора ГПН (Word, Excel, браузер, легкая база данных). Бюджет ограничен.
2. АРМ специалиста по видеонаблюдению (монтаж 4K-роликов с места ЧС, кодирование видео для суда).
3. Сервер отдела аналитики (обработка больших данных, прогнозирование рисков, работа с SQL).
4. Ноутбук начальника караула (работа с документацией в поле, важна автономность батареи).

Вопросы для обсуждения

  1. Почему для офисной работы недостаточно просто самого дешевого процессора? Где проходит граница комфорта?
  2. Почему мощный i9 не нужен инспектору ГПН? Какой вред принесет избыточная производительность?
  3. Как TDP влияет на выбор корпуса и блока питания? Почему игровой ПК нельзя ставить в тесный шкаф?
  4. Что такое гибридная архитектура (P-cores и E-cores) в процессоре i5/i9? Зачем она нужна?
