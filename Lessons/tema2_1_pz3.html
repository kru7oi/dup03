Теория

Цель детального анализа базового ПО

В отличие от ПЗ 1, где мы рассматривали общие понятия, здесь мы проводим детальный анализ базового ПО конкретного компьютера с использованием системных утилит. Это позволяет:

  • выявить проблемы в работе системы;
  • оптимизировать автозагрузку и службы;
  • обеспечить информационную безопасность;
  • спланировать модернизацию АРМ.

Инструменты анализа базового ПО

Инструмент Команда / Запуск Что показывает
Сведения о системе msinfo32 Полная информация об ОС, железе, драйверах
Версия Windows winver Версия и сборка ОС
Диагностика DirectX dxdiag Видеокарта, звук, устройства ввода
Диспетчер задач Ctrl+Shift+Esc Процессы, автозагрузка, производительность
Конфигурация системы msconfig Автозагрузка, службы, параметры загрузки
Командная строка cmd / PowerShell Сетевые настройки, диагностика
Параметры → Приложения GUI Список установленных программ

Что анализировать

  • Версия и сборка ОС: актуальна ли, есть ли обновления безопасности
  • Драйверы устройств: все ли установлены, нет ли конфликтов
  • Автозагрузка: какие программы запускаются при старте (можно отключить лишнее)
  • Службы: какие системные службы работают, нужны ли все
  • Сетевые настройки: IP-адрес, DNS, состояние сетевых адаптеров
  • Средства безопасности: антивирус, брандмауэр, обновления
Важно для специалиста ПС На АРМ в пожарной охране часто возникают проблемы: устаревшие драйверы, лишние программы в автозагрузке, неактуальные обновления безопасности. Специалист, умеющий проводить базовый анализ СПО, может самостоятельно выявить и устранить многие проблемы до приезда IT-специалиста.

Задание 2. Анализ автозагрузки

Открой Диспетчер задач (Ctrl+Shift+Esc) → вкладка «Автозагрузка». Выпиши 5 программ из автозагрузки и определи, какие из них можно отключить без ущерба для работы.

Домашнее задание

Проведи анализ базового ПО на домашнем компьютере (или в компьютерном классе). Подготовь краткий отчёт (1 страница), в котором укажи: версию ОС, количество установленных программ, 3 программы в автозагрузке, которые можно отключить, и рекомендации по оптимизации работы системы.
