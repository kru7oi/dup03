Теория

Что такое базовое (системное) ПО

Базовое (системное) программное обеспечение — это совокупность программ, обеспечивающих работу компьютера как единого комплекса: управление аппаратными ресурсами, взаимодействие с пользователем и создание среды для выполнения прикладных программ.

Состав системного ПО

Группа Что входит Назначение
Операционные системы Windows, Astra Linux, ALT Linux, ROSA, macOS Управление ресурсами ПК, интерфейс с пользователем
Драйверы устройств Драйверы видеокарты, принтера, сетевого адаптера Обеспечение работы конкретного оборудования
Системные утилиты Антивирус, дефрагментация, очистка диска, диагностика Обслуживание и оптимизация системы
Оболочки и среды Total Commander, Far Manager, PowerShell, Bash Расширенные возможности работы с файлами и системой
Сервисные программы Архиваторы (7-Zip, WinRAR), файловые менеджеры Дополнительные системные функции

Ключевые характеристики ОС

  • Разрядность: 32-бит (x86) или 64-бит (x64)
  • Версия и сборка: например, Windows 10 Pro 22H2
  • Тип лицензии: OEM, Retail, Volume (корпоративная)
  • Поддержка оборудования: совместимость с драйверами
  • Безопасность: сертификаты ФСТЭК, поддержка гостайны
  • Интерфейс: GUI (графический) или CLI (командная строка)
Специфика для ПС В пожарно-спасательных подразделениях всё чаще используются российские ОС (Astra Linux, ALT Linux) — они сертифицированы ФСТЭК и соответствуют требованиям импортозамещения. Специалист ПС должен уметь работать как с Windows, так и с Linux-системами.

Практика

Задание 1. Анализ базового ПО на рабочем месте

Открой на своём компьютере сведения о системе (в Windows: Параметры → Система → О системе или команда winver). Заполни таблицу характеристиками базового ПО.

Компонент Характеристика Значение (на твоём ПК)
Операционная система Название, версия, разрядность
Тип лицензии OEM / Retail / Volume / не активирована
Процессор Модель, тактовая частота
Оперативная память Объём ОЗУ
Установленные драйверы Перечислить 3-5 основных (видеокарта, звук, сеть)
Системные утилиты Антивирус, архиватор, файловый менеджер
Оболочки / среды PowerShell, CMD, Total Commander и др.
Средства безопасности Брандмауэр, антивирус, шифрование

Задание 2. Выбор ОС для АРМ

Для каждой профессиональной ситуации подбери оптимальную операционную систему и обоснуй выбор.

№ Ситуация ОС Обоснование (1-2 предложения)
1 АРМ инспектора ГПН (работа с АИС «Электронный инспектор», MS Office)
2 АРМ диспетчера ПСГ с доступом к сведениям ограниченного доступа
3 АРМ аналитика МЧС (обработка больших данных, Python, СУБД)

Результат занятия

  • Знаю состав базового (системного) ПО
  • Умею определять характеристики ОС на рабочем компьютере
  • Понимаю разницу между Windows и российскими ОС (Astra Linux, ALT Linux)
  • Могу обосновать выбор ОС для АРМ специалиста ПС
