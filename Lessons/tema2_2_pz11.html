Раздел 2 / Тема 2.2 / ПЗ 17

Отработка навыка создания и оформления таблиц в MS Word

Тема 2.2 Практическое занятие 1 ак. час ОК.01, ОК.02, ОК.04 · ДПК.3.1 · ПР.02, ПР.06

Цель занятия

Цель: отработать навык создания, редактирования и оформления таблиц в MS Word или его аналоге, научиться структурировать служебную информацию в табличной форме для учёта, проверки, отчётности и инструктажей.

Задачи занятия
  • раскрыть назначение таблиц в текстовых документах;
  • изучить структуру таблицы: строки, столбцы, ячейки, заголовок, примечания;
  • освоить способы создания таблиц;
  • научиться добавлять и удалять строки и столбцы, объединять и разделять ячейки;
  • отработать форматирование границ, заливки, выравнивания и ширины столбцов;
  • создать таблицу учёта первичных средств пожаротушения по заданным данным;
  • сохранить документ в требуемом формате.
Формируемые компетенции и результаты
  • ОК.01 — выбирать способы решения профессиональных задач;
  • ОК.02 — использовать современные информационные технологии;
  • ОК.04 — организовывать самостоятельную работу и представлять результат;
  • ДПК.3.1 — работать с программным обеспечением, установленным в подразделениях;
  • ПР.02 — понимать принципы работы с прикладным программным обеспечением;
  • ПР.06 — создавать структурированные документы, включая табличные формы.
Программная среда Работа выполняется в MS Word или аналоге: LibreOffice Writer, Р7-Офис Writer, МойОфис Документы. Названия команд могут отличаться, но логика создания и форматирования таблиц сохраняется.

План занятия на 45 минут

Этап Время Содержание
I. Вводный инструктаж 0–5 мин Постановка задачи. Зачем специалисту пожарной безопасности нужны таблицы.
II. Теоретический блок 5–20 мин Назначение таблиц, структура, создание, редактирование, форматирование, профессиональные примеры.
III. Практическая работа 20–40 мин Создание и оформление таблицы учёта первичных средств пожаротушения.
IV. Итоги 40–45 мин Проверка файлов, разбор ошибок, выставление оценки, домашнее задание.

Теоретический блок

1. Назначение таблиц

Таблица — это форма представления информации в виде строк и столбцов, позволяющая структурировать данные, сравнивать показатели и быстро находить нужные сведения.

Таблицы применяются там, где сплошной текст становится трудным для восприятия. Например, перечень огнетушителей, гидрантов, проверок, инструктажей, сил и средств лучше воспринимается в таблице, чем в виде длинного абзаца.

Тип информации Почему лучше оформить таблицей
Учёт оборудования Видно количество, место установки, сроки проверки, ответственных лиц
Результаты проверок Можно быстро сравнить нарушения по объектам, датам, ответственным
Расчёт сил и средств Наглядно отображаются подразделения, техника, люди, время прибытия
Инструктажи и обучение Удобно фиксировать ФИО, дату, подпись, вид инструктажа
Графики дежурств Позволяют увидеть смены, замены, нагрузку
Профессиональный смысл Таблица в служебном документе — это не украшение. Это инструмент снижения ошибки. Если адрес, дата, количество или ответственный лицо указаны в таблице, вероятность упустить важный элемент ниже, чем в длинном тексте.

2. Структура таблицы

Любая таблица состоит из основных элементов.

Элемент Описание
Строка Горизонтальный ряд ячеек
Столбец Вертикальный ряд ячеек
Ячейка Пересечение строки и столбца, содержит данные
Заголовок таблицы Первая строка, в которой указаны наименования столбцов
Боковик Первый столбец, содержащий наименования строк, если он есть
Тело таблицы Основные данные без заголовков
Примечание Пояснение под таблицей или в отдельной строке

Пример структуры

№ Наименование Место установки Количество Дата проверки
1 Огнетушитель ОП-5 1 этаж, коридор 2 10.10.2026
2 Огнетушитель ОУ-3 2 этаж, серверная 1 10.10.2026

3. Способы создания таблиц

В текстовом процессоре таблицу можно создать несколькими способами.

Способ Как выполняется Когда удобен
По сетке Вкладка «Вставка» → «Таблица» → выбрать количество строк и столбцов мышью Для небольших простых таблиц
Диалог вставки таблицы Ввести точное число строк и столбцов Когда известно точное количество ячеек
Преобразование текста в таблицу Текст с разделителями, например табуляцией или точкой с запятой, преобразуется в таблицу Когда данные уже есть в текстовом виде
Таблица Excel / электронная таблица Встраивание объекта электронной таблицы Когда нужны формулы и сортировка
Рисование таблицы Вручную задать границы ячеек Для нестандартных форм, бланков
Для текущего занятия Используйте обычный способ: «Вставка» → «Таблица» → укажите нужное количество строк и столбцов.

4. Редактирование таблицы

После создания таблицы её структуру можно изменять.

Действие Назначение
Добавить строку Увеличить количество записей
Добавить столбец Добавить новый показатель, например «Примечание» или «Ответственный»
Удалить строку / столбец Убрать лишние данные
Объединить ячейки Создать общий заголовок или крупный блок
Разбить ячейку Вернуть структуру, если ячейка была объединена
Изменить ширину столбца Сделать таблицу читаемой, перенести длинные слова
Изменить высоту строки Увеличить место для текста
Повтор заголовка Если таблица переходит на следующую страницу, заголовок повторяется

5. Форматирование таблицы

Форматирование таблицы делает её понятной и аккуратной. Основные параметры:

  • Границы — линии между ячейками. Для служебных документов обычно используют тонкие сплошные линии.
  • Заливка — цвет фона ячейки. Заголовок можно выделить светло-серым цветом. Яркие цвета нежелательны.
  • Выравнивание текста — по левому краю для названий, по центру для номеров и дат, по правому краю для денежных сумм, если они есть.
  • Шрифт — обычно тот же, что и в документе, но заголовок можно сделать полужирным.
  • Автоподбор ширины — столбцы подстраиваются под содержимое.
  • Перенос слов — предотвращает выход текста за границы таблицы.

Рекомендации по выравниванию

Тип данных Выравнивание
Номер строки по центру
Наименование объекта по левому краю
Количество по центру или по правому краю
Дата по центру
ФИО ответственного по левому краю
Примечание по левому краю

6. Таблицы в профессиональной деятельности пожарной охраны

В службе таблицы используются постоянно. Примеры:

  • учёт огнетушителей и пожарных кранов;
  • перечень гидрантов и источников водоснабжения;
  • журнал инструктажей по пожарной безопасности;
  • график дежурств личного состава;
  • ведомость проверки зданий и сооружений;
  • расчёт сил и средств на вызов;
  • перечень нарушений и сроков устранения;
  • учёт средств индивидуальной защиты;
  • статистика пожаров по районам, месяцам, типам объектов.
Пример профессиональной задачи Инспектору ГПН нужно оформить результат проверки. Вместо длинного текста удобнее сделать таблицу: «№ нарушения», «Описание», «Нормативный пункт», «Срок устранения», «Ответственный». Такая таблица снижает риск упустить пункт предписания.

7. Типичные ошибки при работе с таблицами

Ошибка Последствие Как избежать
Слишком много столбцов Таблица не помещается на страницу, плохо читается Оставить только необходимые показатели
Нет заголовков столбцов Непонятно, какие данные указаны Первая строка всегда должна пояснять столбец
Разный шрифт в ячейках Документ выглядит небрежно Использовать единый шрифт и размер
Яркая заливка всех ячеек Таблица теряет служебный вид Заливать только заголовок, при необходимости — итоговую строку
Длинные тексты в узких столбцах Строки становятся очень высокими, таблица «ломается» Изменить ширину столбцов или перенести пояснения в примечание
Номера и даты выровнены по левому краю Сложнее сравнивать данные Использовать центральное выравнивание для коротких данных
Таблица создана «из пробелов и тире» Нельзя редактировать, сортировать, форматировать Использовать настоящую таблицу текстового процессора

Практическая работа

Цель работы: создать и оформить таблицу учёта первичных средств пожаротушения на условном объекте.

Формат: индивидуальная работа за ПК в текстовом редакторе.

Что нужно сделать

Создайте документ, добавьте заголовок, вставьте таблицу, заполните её данными из списка ниже, отформатируйте границы, заголовок, выравнивание и ширину столбцов. Сохраните файл для сдачи.

Исходные данные для таблицы

Используйте следующие сведения. Их нужно не копировать как текст, а внести в таблицу.

  1. Огнетушитель порошковый ОП-5 — 1 этаж, коридор у входа — количество 2 — дата проверки 10.10.2026 — ответственный Сидоров А. В. — примечание: пломбы целы.
  2. Огнетушитель углекислотный ОУ-3 — 2 этаж, серверная — количество 1 — дата проверки 10.10.2026 — ответственный Сидоров А. В. — примечание: требуется проверка массы.
  3. Огнетушитель порошковый ОП-5 — 3 этаж, у лестницы — количество 2 — дата проверки 09.10.2026 — ответственный Петрова М. И. — примечание: бирка читается частично.
  4. Пожарный кран ПК-1 — 2 этаж, коридор блока А — количество 1 — дата проверки 08.10.2026 — ответственный Иванов П. С. — примечание: рукав уложен правильно.
  5. Пожарный кран ПК-2 — 4 этаж, холл — количество 1 — дата проверки 08.10.2026 — ответственный Иванов П. С. — примечание: отсутствует ствол.
  6. Огнетушитель порошковый ОП-10 — котельная — количество 1 — дата проверки 07.10.2026 — ответственный Кузнецов В. Р. — примечание: установлен вне зоны доступа людей.

Необходимые столбцы таблицы

№ столбца Наименование столбца Что заполнять
1 № Порядковый номер строки
2 Наименование средства Огнетушитель или пожарный кран с маркой
3 Место установки Этаж и помещение
4 Количество, шт. Число
5 Дата проверки ДД.ММ.ГГГГ
6 Ответственный Фамилия И. О.
7 Примечание Краткое замечание

Задание

Выполните работу по алгоритму.

  1. Создайте новый документ.
  2. Установите альбомную ориентацию страницы, если таблица не помещается в книжной ориентации. Для данной таблицы рекомендуется альбомная ориентация.
  3. Установите поля: левое 20 мм, правое 15 мм, верхнее и нижнее 20 мм.
  4. Введите заголовок документа: Учёт первичных средств пожаротушения на условном объекте.
  5. Оформите заголовок по центру, полужирным, шрифт Times New Roman, 14 пт.
  6. Вставьте таблицу размером 7 столбцов и 7 строк: 1 строка заголовка и 6 строк данных.
  7. Заполните первую строку названиями столбцов.
  8. Заполните остальные строки данными из исходного списка.
  9. Выделите строку заголовка полужирным начертанием.
  10. Залейте строку заголовка светло-серым цветом.
  11. Установите границы таблицы: все ячейки, сплошная линия, толщина 0,5–1 пт.
  12. Выровняйте столбец «№» по центру.
  13. Выровняйте столбец «Количество, шт.» по центру.
  14. Выровняйте столбец «Дата проверки» по центру.
  15. Столбцы «Наименование средства», «Место установки», «Ответственный», «Примечание» выровняйте по левому краю.
  16. Настройте ширину столбцов так, чтобы текст не выходил за границы и не было чрезмерно пустых колонок.
  17. При необходимости включите перенос слов в ячейках.
  18. Добавьте под таблицей примечание: Примечание: проверка проводится не реже одного раза в квартал.
  19. Оформите примечание курсивом, без абзацного отступа или с небольшим отступом слева.
  20. Добавьте нижний колонтитул: ДУП.03 · ПЗ 17 · Фамилия И.О. · Группа.
  21. Сохраните файл под именем ФамилияИО_группа_ПЗ17.docx.
Дополнительное задание для сильных студентов Добавьте итоговую строку «Всего огнетушителей» и посчитайте общее количество огнетушителей. Если в текстовом процессоре доступна формула, используйте её. Если нет — введите значение вручную, но покажите ход расчёта в примечании.

Критерии оценки

Оценка Критерии
5 Таблица создана корректно: 7 столбцов, 7 строк. Все данные внесены без ошибок. Заголовок выделен, границы установлены, выравнивание соответствует типу данных. Ширина столбцов настроена. Есть примечание и колонтитул. Файл назван правильно.
4 Таблица выполнена верно, но есть 1–2 незначительные недоработки: например, не настроена ширина одного столбца, примечание оформлено без курсива, выравнивание даты не по центру.
3 Таблица создана, но допущены существенные ошибки: пропущены данные, нет заголовков столбцов, таблица не отформатирована, нарушена структура, файл назван неправильно.
2 Таблица не создана, данные оформлены текстом, работа не сдана, обнаружено списывание либо таблица не соответствует заданию.
Что особенно проверяется
  • настоящая таблица, а не текст с тире и пробелами;
  • корректное количество строк и столбцов;
  • заголовки столбцов;
  • границы таблицы;
  • выделение строки заголовка;
  • выравнивание номеров, количеств и дат;
  • читаемость ширины столбцов;
  • наличие примечания и колонтитула.
