Раздел 1 · Тема 1.2 · Практическое занятие 2

Проведение анализа комплектации компьютерного рабочего места в соответствии с целями его использования для различных направлений деятельности

📚 Вид: Практическое занятие (ПЗ) ⏱️ Объём: 1 ак. час (45 мин) 📍 Формат: очный

🎯 Цели и задачи занятия

🎯 Цель:

Научить обучающихся подбирать оптимальную конфигурацию компьютерного рабочего места (АРМ) в зависимости от профессиональных задач специалиста пожарной безопасности, учитывая требования к производительности, надежности, эргономике и совместимости программного обеспечения.

Формируемые результаты (согласно РП):

ОК.02 ДПК.3.1 ЛР.03 ЦО.02 МР.03 ПР.01–07

🔤 Аббревиатуры занятия

Ключевые сокращения, используемые в материале:
  • АРМ – Автоматизированное рабочее место
  • ЦП – Центральный процессор
  • ОЗУ – Оперативное запоминающее устройство
  • ПЗУ – Постоянное запоминающее устройство
  • HDD – Жесткий диск (Hard Disk Drive)
  • SSD – Твердотельный накопитель (Solid State Drive)
  • ГПН – Государственный пожарный надзор
  • ПС – Пожарно-спасательное подразделение
  • ПО – Программное обеспечение

📋 План занятия (45 минут)

0–5 мин

I. Вводный инструктаж

Постановка задачи. Почему нельзя использовать одинаковую конфигурацию ПК для всех специалистов?

5–15 мин

II. Критерии подбора комплектации

Разбор ключевых параметров: производительность, надежность, эргономика, совместимость с ПО.

15–35 мин

III. Практическая работа: подбор конфигурации

Работа в группах. Каждая группа подбирает комплектацию АРМ для конкретной профессиональной задачи.

35–45 мин

IV. Защита результатов и обсуждение

Презентация конфигураций, сравнение, выводы.

📐 Критерии подбора комплектации АРМ

При подборе конфигурации компьютерного рабочего места необходимо учитывать следующие параметры:

Критерий Что оценивается Примеры требований
1. Производительность Скорость обработки данных, многозадачность Мощный ЦП (Intel Core i5/i7 или AMD Ryzen 5/7), 16+ ГБ ОЗУ, SSD
2. Надежность Стабильность работы, отказоустойчивость Качественные компоненты, резервное питание (ИБП), RAID-массивы
3. Специализированное ПО Требования программного обеспечения к ресурсам ГИС-системы требуют видеокарту; СУБД — много ОЗУ; САПР — мощный ЦП
4. Эргономика Удобство работы, здоровье пользователя Монитор 24"+, удобная клавиатура, регулировка высоты стола
5. Мобильность Необходимость работы вне офиса Ноутбук/планшет для РТП на месте ЧС; стационарный ПК для инспектора
6. Бюджет Стоимость комплектации Баланс между стоимостью и необходимыми характеристиками

💼 Практическая работа: Подбор конфигурации АРМ

Работая в группах (3–4 человека), подберите оптимальную комплектацию компьютерного рабочего места для одной из профессиональных задач. Обоснуйте выбор каждого компонента.

🔹 Вариант 1: АРМ инспектора государственного пожарного надзора (ГПН)

Задачи: работа с АИС «Электронный инспектор», ведение реестра проверок, формирование предписаний, работа с текстовыми документами и таблицами, интернет-поиск нормативных актов.

Условия: стационарное рабочее место в офисе, работа 8 часов в день, необходимость чтения больших объемов текста.

🔹 Вариант 2: АРМ руководителя тушения пожара (РТП) на месте ЧС

Задачи: работа с ГИС-картами в полевых условиях, прием данных с датчиков, связь с диспетчерской, работа в экстремальных условиях (пыль, влага, перепады температур).

Условия: мобильность, работа на улице и в задымленных помещениях, ограниченное время автономной работы.

🔹 Вариант 3: АРМ аналитика МЧС России

Задачи: обработка больших объемов статистических данных, построение графиков и диаграмм, работа с СУБД, анализ тенденций пожаров, подготовка отчетов.

Условия: стационарное рабочее место, необходимость быстрой обработки больших массивов данных, работа с несколькими мониторами.

🔹 Вариант 4: АРМ проектировщика систем противопожарной защиты

Задачи: работа в САПР (Компас-3D, AutoCAD), создание чертежей и 3D-моделей, расчет параметров систем пожаротушения, работа с большими графическими файлами.

Условия: стационарное рабочее место, необходимость высокой производительности при рендеринге, точная цветопередача монитора.

💬 Вопросы для обсуждения

  1. Почему для РТП на месте ЧС критически важна мобильность и защищенность устройства, а не максимальная производительность?
  2. Какие компоненты можно "экономить" для инспектора ГПН, а какие — нельзя?
  3. Почему аналитику нужен более мощный процессор и больше ОЗУ, чем инспектору?
  4. Как требования программного обеспечения влияют на выбор комплектации?

📌 Задание:

Укажите точную модель, характеристики и цену. Обоснуйте, почему эта конфигурация подходит для выбранной профессиональной задачи.
