Раздел 1 / Тема 1.2 / ПЗ 5

Проведение анализа комплектации компьютерного рабочего места в соответствии с целями его использования для различных направлений деятельности

Тема 1.2 Практическое занятие 1 ак. час ОК.02 · ДПК.3.1 · МР.03 · ПР.01–07

Цель занятия

Научиться подбирать оптимальную конфигурацию автоматизированного рабочего места (АРМ) в зависимости от профессиональных задач специалиста пожарной безопасности, учитывая требования к производительности, надежности, эргономике и совместимости программного обеспечения.

Формируемые компетенции:
  • ОК.02 — использовать современные средства поиска, анализа и интерпретации информации;
  • ДПК.3.1 — работать с программным обеспечением, установленным в ПС;
  • ПР.02 — понимать принципы устройства и функционирования современных стационарных и мобильных компьютеров.

План занятия (45 минут)

  1. 0–5 мин. Вводный инструктаж: постановка задачи, обсуждение важности индивидуального подхода к оборудованию.
  2. 5–15 мин. Теория: разбор критериев подбора комплектации АРМ.
  3. 15–35 мин. Практическая работа: подбор конфигурации для выбранного варианта задачи.
  4. 35–45 мин. Защита результатов, сравнение решений, домашнее задание.

Критерии подбора комплектации АРМ

При выборе компонентов компьютера необходимо учитывать шесть основных параметров:

Критерий Что оценивается Примеры требований
Производительность Скорость обработки данных, многозадачность Мощный ЦП (Core i5/i7), 16+ ГБ ОЗУ, быстрый SSD.
Надежность Стабильность работы, отказоустойчивость Качественные компоненты, ИБП, RAID-массивы.
Специализированное ПО Требования программ к ресурсам ГИС требует видеокарту; САПР — мощный ЦП и ОЗУ.
Эргономика Удобство работы, здоровье пользователя Монитор 24"+ IPS, удобная клавиатура, регулируемый стол.
Мобильность Необходимость работы вне офиса Ноутбук/планшет для РТП; стационарный ПК для инспектора.
Бюджет Стоимость комплектации Баланс между ценой и необходимыми характеристиками.

Практическая работа: Подбор конфигурации АРМ

Работая в группах (3–4 человека), выберите один из четырех вариантов профессиональной задачи ниже. Подберите оптимальную комплектацию компьютера для этого специалиста и обоснуйте выбор каждого компонента.

Варианты задач

Вариант 1. АРМ инспектора ГПН

Задачи: работа с АИС «Электронный инспектор», ведение реестра проверок, формирование предписаний, текстовые документы, поиск нормативных актов.

Условия: стационарное рабочее место в офисе, 8 часов в день, большой объем текста.

Вариант 2. АРМ руководителя тушения пожара (РТП)

Задачи: работа с ГИС-картами в поле, прием данных с датчиков, связь с диспетчерской.

Условия: мобильность, экстремальные условия (пыль, влага, температура), ограниченное питание.

Вариант 3. АРМ аналитика МЧС России

Задачи: обработка больших массивов статистики, построение графиков, работа с СУБД, подготовка отчетов.

Условия: стационарное рабочее место, высокая скорость вычислений, несколько мониторов.

Вариант 4. АРМ проектировщика систем противопожарной защиты

Задачи: работа в САПР (Компас-3D, AutoCAD), создание чертежей и 3D-моделей, расчет систем пожаротушения.

Условия: стационарное рабочее место, рендеринг, точная цветопередача.

Вопросы для обсуждения

  1. Почему для РТП на месте ЧС критически важна защищенность и автономность, а не максимальная мощность процессора?
  2. Какие компоненты можно «экономить» для инспектора ГПН, а какие — нельзя?
  3. Почему аналитику нужно больше оперативной памяти, чем проектировщику?
  4. Как требования конкретного программного обеспечения влияют на выбор железа?

Домашнее задание

Задание:

Найдите в интернет-магазинах электроники (DNS, Ситилинк, ОнлайнТрейд) реальную готовую конфигурацию компьютера или ноутбука, подходящую для одного из рассмотренных сегодня вариантов АРМ.

Укажите точную модель, характеристики и цену. Обоснуйте письменно, почему эта конфигурация подходит для выбранной профессиональной задачи.
