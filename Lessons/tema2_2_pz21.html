Раздел 2 / Тема 2.2 / ПЗ 27

Добавление макросов в базу данных

Тема 2.2 Практическое занятие 1 ак. час ОК.01, ОК.02, ОК.04 · ДПК.3.1 · ПР.06

Цель занятия

Цель: научиться добавлять в базу данных Эксель макросы для автоматизации ввода, очистки формы и поиска записей, а также размещать кнопки управления на листе формы.

Задачи занятия
  • включить вкладку «Разработчик»;
  • сохранить файл в формате с поддержкой макросов;
  • записать простой макрос очистки формы;
  • создать макрос переноса данных из карточки в реестр;
  • создать макрос поиска записи по инвентарному номеру;
  • назначить макросы на кнопки;
  • проверить работу базы данных на корректных и некорректных данных;
  • оформить протокол испытаний.
Формируемые компетенции и результаты
  • ОК.01 — выбирать способы автоматизации профессиональных задач;
  • ОК.02 — использовать информационные технологии для обработки данных;
  • ОК.04 — организовывать работу с программными средствами и контролировать результат;
  • ДПК.3.1 — работать с программным обеспечением подразделений;
  • ПР.06 — наполнять базу данных, использовать вычисляемые поля, выполнять поиск и обработку записей.

Теоретический блок

1. Что такое макрос

Макрос — это сохранённая последовательность действий, которую можно выполнить одной командой или нажатием кнопки.

Макрос может:

  • очистить поля формы;
  • перенести данные из карточки в реестр;
  • найти запись по номеру;
  • отсортировать таблицу;
  • вывести сообщение пользователю;
  • проверить, заполнены ли обязательные поля.

В Эксель макросы записываются и выполняются с помощью встроенного языка программирования. Для базового уровня достаточно уметь записать простой макрос и внести небольшие изменения в готовый код.

2. Безопасность макросов

Макросы могут быть опасны, если файл получен из ненадёжного источника. Поэтому Эксель по умолчанию блокирует выполнение макросов.

Правила безопасной работы:

  1. Не запускайте макросы из файлов, полученных из интернета или от неизвестных отправителей.
  2. Используйте формат файла с поддержкой макросов только тогда, когда макросы действительно нужны.
  3. Проверяйте, какие действия выполняет макрос, перед запуском.
  4. Храните учебные файлы в согласованной папке.
Важно Обычный файл книги Эксель не сохраняет макросы. Для работы с макросами нужно сохранять файл в формате с поддержкой макросов.

3. Вкладка «Разработчик»

Для работы с макросами нужна вкладка «Разработчик». По умолчанию она может быть скрыта.

Чтобы включить её:

  1. Откройте «Файл» → «Параметры».
  2. Перейдите в раздел «Настройка ленты».
  3. В списке основных вкладок отметьте «Разработчик».
  4. Нажмите «ОК».

4. Запись макроса

Запись макроса похожа на видеозапись действий. Эксель запоминает, какие ячейки выделялись, какие команды нажимались, какие значения вводились.

Записывать макрос нужно аккуратно:

  • не делайте лишних движений;
  • не выделяйте лишние ячейки;
  • не меняйте листы без необходимости;
  • помните, что запись может сохранить ошибочное действие.

5. Редактирование кода

Записанный макрос можно улучшить в редакторе кода. Например, добавить проверку пустых полей, сообщение об ошибке, поиск следующей свободной строки.

Для учебного занятия используется готовый код, который нужно поместить в модуль книги. Студент должен понять, какие ячейки читает макрос и в какие столбцы реестра он записывает данные.

6. Кнопки и назначение макросов

Кнопка делает макрос удобным для пользователя. Вместо поиска команды в меню пользователь нажимает кнопку с понятной надписью.

Порядок работы:

  1. Вставить кнопку элементов управления.
  2. Изменить надпись кнопки.
  3. Открыть контекстное меню кнопки.
  4. Выбрать «Назначить макрос».
  5. Указать нужный макрос.

7. Макросы в работе специалиста

В подразделениях макросы могут использоваться для:

  • быстрого добавления записей в журнал учёта;
  • очистки карточки после ввода;
  • поиска объекта, гидранта, огнетушителя или инструктажа;
  • формирования справки по кнопке;
  • проверки сроков обслуживания;
  • переноса данных между листами.

Важно понимать: макрос не заменяет знание предмета. Он ускоряет рутинные действия, но требует корректной структуры данных.

Практическая работа

Цель работы: добавить в базу данных макросы очистки формы, добавления записи в реестр и поиска записи по инвентарному номеру.

Формат: индивидуальная работа за ПК.

Основа работы Используйте файл, созданный на ПЗ 26. Если файла нет, воссоздайте листы «Справочники», «Реестр» и «Форма» с теми же ячейками: поля формы находятся в C3:C11, реестр содержит таблицу с заголовками A1:J1.

Шаг 1. Подготовка файла

  1. Откройте файл ПЗ 26.
  2. Проверьте, что на листе «Реестр» есть таблица tblРеестр и заполнено 10 записей.
  3. Проверьте, что на листе «Форма» поля ввода находятся в ячейках C3:C11.
  4. Если лист «Форма» защищён, снимите защиту, чтобы добавить кнопки.
  5. Сохраните файл как новую книгу с поддержкой макросов:
    ФамилияИО_группа_ПЗ27.xlsm
Не сохраняйте макросы в файле с расширением .xlsx Иначе при закрытии файла макросы будут удалены.

Шаг 2. Включение вкладки «Разработчик»

  1. Откройте «Файл» → «Параметры».
  2. Перейдите в «Настройка ленты».
  3. Отметьте вкладку «Разработчик».
  4. Нажмите «ОК».

После этого на ленте появится вкладка «Разработчик». На ней будут кнопки «Записать макрос», «Остановить запись», «Макросы», «Код макроса», «Вставить».

Шаг 3. Запись макроса очистки формы

Создадим простой макрос, который очищает поля карточки.

  1. Перейдите на лист «Форма».
  2. На вкладке «Разработчик» нажмите «Записать макрос».
  3. В поле «Имя макроса» введите: ОчиститьФорму.
  4. В поле «Описание» введите: Очищает поля карточки ввода.
  5. В поле «Расположение в» выберите «Эта книга».
  6. Нажмите «ОК».
  7. Выделите ячейки C3:C11.
  8. На вкладке «Главная» найдите группу «Редактирование».
  9. Нажмите «Очистить» → «Очистить содержимое».
  10. На вкладке «Разработчик» нажмите «Остановить запись».

Проверьте макрос: заполните форму, затем запустите макрос через «Разработчик» → «Макросы» → ОчиститьФорму → «Выполнить».

Шаг 4. Создание макроса добавления записи

Этот макрос будет читать данные из карточки и добавлять новую строку в таблицу на листе «Реестр».

Открытие редактора кода

  1. На вкладке «Разработчик» нажмите «Код макроса».
  2. В окне редактора выберите вашу книгу.
  3. В меню «Вставка» выберите «Модуль».
  4. В появившемся белом окне кода вставьте готовый текст макроса.
Код макроса добавления записи 
Option Explicit

Sub ДобавитьВРеестр()
    Dim wsForm As Worksheet
    Dim wsReg As Worksheet
    Dim lo As ListObject
    Dim lr As ListRow
    Dim invNum As String

    Set wsForm = ThisWorkbook.Worksheets("Форма")
    Set wsReg = ThisWorkbook.Worksheets("Реестр")

    If wsReg.ListObjects.Count = 0 Then
        MsgBox "На листе Реестр нет таблицы. Преобразуйте диапазон с заголовками в таблицу.", vbCritical, "Ошибка"
        Exit Sub
    End If

    Set lo = wsReg.ListObjects(1)
    invNum = CStr(wsForm.Range("C3").Value)

    If invNum = "" Then
        MsgBox "Введите инвентарный номер.", vbExclamation, "Проверка"
        Exit Sub
    End If

    If wsForm.Range("C4").Value = "" Or wsForm.Range("C5").Value = "" Or _
       wsForm.Range("C6").Value = "" Or wsForm.Range("C7").Value = "" Or _
       wsForm.Range("C8").Value = "" Or wsForm.Range("C9").Value = "" Or _
       wsForm.Range("C10").Value = "" Or wsForm.Range("C11").Value = "" Then
        MsgBox "Заполните все поля формы.", vbExclamation, "Проверка"
        Exit Sub
    End If

    If Application.WorksheetFunction.CountIf(wsReg.Range("B2:B1000"), invNum) > 0 Then
        MsgBox "Такой инвентарный номер уже есть в реестре.", vbCritical, "Ошибка"
        Exit Sub
    End If

    Set lr = lo.ListRows.Add

    With lr.Range
        .Cells(1, 1).Value = lo.ListRows.Count
        .Cells(1, 2).Value = wsForm.Range("C3").Value
        .Cells(1, 3).Value = wsForm.Range("C4").Value
        .Cells(1, 4).Value = wsForm.Range("C5").Value
        .Cells(1, 5).Value = wsForm.Range("C6").Value
        .Cells(1, 6).Value = wsForm.Range("C7").Value
        .Cells(1, 7).Value = wsForm.Range("C8").Value
        .Cells(1, 8).Value = wsForm.Range("C9").Value
        .Cells(1, 9).Value = wsForm.Range("C10").Value
        .Cells(1, 10).Value = wsForm.Range("C11").Value
    End With

    wsForm.Range("C3:C11").ClearContents
    wsReg.Activate
    lr.Range.Cells(1, 1).Select
    MsgBox "Запись добавлена в реестр.", vbInformation, "Результат"
End Sub

Пояснение к коду

Часть кода Что делает
Worksheets("Форма") Обращается к листу формы
Worksheets("Реестр") Обращается к листу реестра
ListObjects(1) Берёт первую таблицу на листе «Реестр»
Range("C3").Value Читает инвентарный номер из карточки
CountIf Проверяет, нет ли такого номера в столбце B
ListRows.Add Добавляет новую строку в таблицу
ClearContents Очищает поля формы после переноса

Шаг 5. Создание макроса поиска

Добавьте в тот же модуль второй макрос.

Код макроса поиска записи 
Sub ПоискПоНомеру()
    Dim wsReg As Worksheet
    Dim found As Range
    Dim query As String

    Set wsReg = ThisWorkbook.Worksheets("Реестр")
    query = InputBox("Введите инвентарный номер для поиска:", "Поиск записи")

    If query = "" Then Exit Sub

    Set found = wsReg.Range("B2:B1000").Find(What:=query, LookIn:=xlValues, LookAt:=xlWhole)

    If found Is Nothing Then
        MsgBox "Запись не найдена.", vbInformation, "Поиск"
    Else
        wsReg.Activate
        found.EntireRow.Select
        MsgBox "Найдена запись: " & found.Value, vbInformation, "Поиск"
    End If
End Sub

Этот макрос запрашивает номер, ищет его в столбце B листа «Реестр» и выделяет найденную строку.

Шаг 6. Кнопки управления

Разместите на листе «Форма» три кнопки.

  1. Перейдите на вкладку «Разработчик».
  2. Нажмите «Вставить».
  3. В группе «Элементы управления» выберите «Кнопка».
  4. Нарисуйте кнопку в диапазоне E3:F3.
  5. Щёлкните по кнопке правой кнопкой мыши.
  6. Выберите «Изменить текст» и подпишите: Добавить запись.
  7. Снова щёлкните правой кнопкой мыши и выберите «Назначить макрос».
  8. Выберите макрос ДобавитьВРеестр.

Аналогично создайте кнопки:

  5. Нажмите «Найти запись» и введите XX-999. Должно появиться сообщение, что запись не найдена.

Дополнительное задание для сильных студентов

Добавьте макрос автоматического расчёта даты следующей проверки через 180 дней.

Код дополнительного макроса 
Sub СледующаяПроверкаЧерезПолгода()
    Dim wsForm As Worksheet
    Dim baseDate As Date

    Set wsForm = ThisWorkbook.Worksheets("Форма")

    If Not IsDate(wsForm.Range("C8").Value) Then
        MsgBox "В поле даты ввода в эксплуатацию нет корректной даты.", vbExclamation, "Проверка"
        Exit Sub
    End If

    baseDate = CDate(wsForm.Range("C8").Value)
    wsForm.Range("C9").Value = baseDate + 180
    MsgBox "Дата следующей проверки заполнена.", vbInformation, "Результат"
End Sub

Создайте кнопку с надписью «Рассчитать проверку» и назначьте ей этот макрос.
