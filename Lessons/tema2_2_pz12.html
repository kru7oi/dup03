Раздел 2 / Тема 2.2 / ПЗ 18

Создание документа с указанной структурой в MS Word

Тема 2.2 Практическое занятие 1 ак. час ОК.01, ОК.02, ОК.04 · ДПК.3.1 · ПР.06

Цель занятия

Цель: научиться создавать сложные текстовые документы с четкой иерархической структурой, используя стили заголовков, многоуровневые списки и разрывы разделов для оформления служебной документации.

Задачи занятия
  • понять различие между простым форматированием и логической структурой;
  • освоить применение стилей «Заголовок 1», «Заголовок 2», «Заголовок 3»;
  • научиться настраивать многоуровневые списки с автоматической нумерацией;
  • отработать использование разрывов разделов для смены ориентации или нумерации;
  • оформить инструкцию по действиям при пожаре в соответствии с заданной структурой.
Формируемые компетенции и результаты
  • ОК.01 — выбирать способы решения профессиональных задач;
  • ОК.02 — использовать информационные технологии для создания документов;
  • ОК.04 — организовывать работу над сложным документом;
  • ДПК.3.1 — работать с программным обеспечением подразделений;
  • ПР.06 — создавать структурированные текстовые документы.

План занятия на 45 минут

Этап Время Содержание
I. Вводный инструктаж 0–5 мин Объяснение важности структуры для навигации и восприятия информации.
II. Теоретический блок 5–20 мин Иерархия заголовков, многоуровневые списки, разрывы разделов, примеры из практики МЧС.
III. Практическая работа 20–40 мин Создание документа «Инструкция по эвакуации» с заданной структурой.
IV. Итоги 40–45 мин Проверка структуры, выставление оценки, домашнее задание.

Теоретический блок

1. Что такое структура документа

Структура документа — это логическая организация текста, где каждый фрагмент имеет свой уровень значимости и место в общей иерархии.

Простое выделение жирным шрифтом не создает структуру. Оно лишь визуально выделяет текст. Настоящая структура формируется через стили заголовков. Когда вы применяете стиль «Заголовок 1», Word понимает: «Это начало нового крупного раздела». Стиль «Заголовок 2» означает: «Это подраздел внутри предыдущего раздела».

Зачем нужна логическая структура?
  • Для автоматического построения оглавления (следующее занятие).
  • Для удобной навигации по длинным документам (панель Навигации).
  • Для корректного отображения в электронных архивах и системах управления документами.
  • Для единообразия оформления всей документации подразделения.

2. Иерархия заголовков

В служебных документах обычно используется трехуровневая система:

Стиль Назначение Пример использования
Заголовок 1 Название основного раздела или главы «I. Общие положения», «II. Порядок действий»
Заголовок 2 Подраздел, пункт инструкции «2.1. Действия персонала», «2.2. Действия ответственного лица»
Заголовок 3 Мелкий подпункт, детальное описание «2.1.1. При обнаружении дыма», «2.1.2. При получении сигнала тревоги»

3. Многоуровневые списки и нумерация

Для пронумерованных разделов часто используют многоуровневые списки. Это позволяет автоматически менять нумерацию при добавлении или удалении пунктов.

Как настроить многоуровневый список
  1. Выделите текст или поставьте курсор в начало абзаца.
  2. На вкладке «Главная» выберите кнопку «Многоуровневый список».
  3. Выберите шаблон с цифрами и буквами (например, 1., 1.1., 1.1.1.).
  4. Если нужно изменить вид нумерации, нажмите «Определить новый многоуровневый список».
  5. В окне настройки свяжите уровни списка со стилями заголовков («Заголовок 1» ↔ Уровень 1).

4. Разрывы разделов и колонтитулы

Разрыв раздела позволяет менять параметры страницы внутри одного документа.

Примеры применения в работе специалиста пожарной безопасности:

  • Титульный лист без нумерации, основной текст с нумерацией.
  • Основной текст книжной ориентации, приложения (чертежи, схемы) — альбомной.
  • Разные колонтитулы для разных глав отчета.
Важно Не используйте пустые строки и Enter для перехода на новую страницу или смены ориентации. Используйте только команду «Макет» → «Разрывы» → «Следующая страница» или «Непрерывный».

5. Структура типовых документов МЧС

Большинство нормативных и служебных документов имеют жесткую структуру.

Тип документа Характерная структура
Инструкция по охране труда / ПБ 1. Общие требования
2. Требования перед началом работы
3. Требования во время работы

Практическая работа

Цель работы: создать документ «Инструкция по действиям персонала при пожаре» с использованием стилей заголовков, многоуровневого списка и разрыва разделов.

Формат: индивидуальная работа за ПК.

Задание

  1. Создайте новый документ.
  2. Установите поля: левое 30 мм, правое 15 мм, верхнее и нижнее 20 мм.
  3. Введите название документа: ИНСТРУКЦИЯ ПО ДЕЙСТВИЯМ ПЕРСОНАЛА ПРИ ПОЖАРЕ. Оформите его как обычный текст (без стиля Заголовок), по центру, полужирным, капсом.
  4. Вставьте разрыв раздела («Макет» → «Разрывы» → «Следующая страница»). Это отделит титульную часть от основного текста.
  5. На второй странице начните оформлять структуру инструкции.
  6. Для каждого основного пункта (I, II, III...) примените стиль «Заголовок 1». Настройте стиль так, чтобы он имел номер римскими цифрами (I., II., III.) и был выровнен по левому краю.
  7. Для подпунктов (1.1, 1.2...) примените стиль «Заголовок 2». Настройте арабскую нумерацию.
  8. Для деталей (1.1.1, 1.1.2...) примените стиль «Заголовок 3».
  9. Внутри пунктов используйте маркированные списки для перечисления действий.
  10. Добавьте нумерацию страниц начиная со второй страницы (внизу по центру). Первая страница (титульная) не должна иметь номера.
  11. Сохраните файл как ФамилияИО_группа_ПЗ18.docx.

Исходные данные для структуры

Используйте следующий текст для заполнения уровней заголовков:

I. Общие положения
1.1. Настоящая инструкция определяет порядок действий работников организации при возникновении пожара.
1.2. Ответственность за соблюдение требований настоящей инструкции несет руководитель объекта.

II. Действия при обнаружении пожара
2.1. Немедленно сообщить о пожаре.
2.1.1. Позвонить в пожарную охрану по номеру 101 или 112.
2.1.2. Назвать адрес объекта, место возгорания, свои ФИО.
2.2. Организовать оповещение людей.
2.2.1. Включить систему оповещения и управления эвакуацией (СОУЭ).
2.2.2. Голосом предупредить находящихся в помещении людей.

III. Эвакуация людей
3.1. Руководствоваться планом эвакуации.
3.1.1. Направлять людей к ближайшим запасным выходам.
3.1.2. Не допускать паники и толкотни.
3.2. Проверить наличие людей в помещениях.
3.2.1. Осмотреть туалеты, кладовые, кабинеты.
3.2.2. Доложить ответственному лицу о количестве эвакуированных.

IV. Тушение пожара первичными средствами
4.1. Использовать огнетушители и пожарные краны только при отсутствии угрозы жизни.
4.1.1. При тушении электрооборудования предварительно обесточить его.
4.1.2. Не приближаться к очагу возгорания ближе безопасного расстояния.

V. Действия после прибытия пожарных подразделений
5.1. Встретить пожарные расчеты.
5.2. Передать информацию руководителю тушения пожара (РТП).
5.2.1. Сообщить о наличии людей в здании.
5.2.2. Указать расположение источников водоснабжения.

Форма сдачи работы

Элемент Требование
Имя файла ФамилияИО_группа_ПЗ18.docx
Структура Использованы стили Заголовок 1, 2, 3. Есть многоуровневая нумерация.
Разделы Есть разрыв раздела между титульным листом и основным текстом.
Нумерация Номера страниц начинаются со 2-й страницы.

Критерии оценки

Оценка Критерии
5 Структура полностью соответствует заданию. Стили применены правильно. Нумерация автоматическая. Разрыв раздела настроен верно. Нумерация страниц корректна.
4 Структура есть, но есть мелкие ошибки в настройке нумерации уровней или применении стилей. Разрыв раздела выполнен, но нумерация страниц может быть не идеальной.
3 Документ имеет заголовки, но они набраны вручную (жирным шрифтом), а не стилями. Нет многоуровневой нумерации. Разрыв раздела отсутствует или выполнен неправильно.
2 Документ представляет собой сплошной текст без явной структуры. Задание не выполнено.
